# 12. 빠른 메뉴 · 환율 계산기 · 설정

- 문서 상태: 초안 v0.1 (2026-10-22)
- 범위 정리: **가계부(지출 기록·예산·정산)는 제외** 상태 유지. 환율은 **조회·계산 도구**로만 제공하고, 지출을 저장하지 않는다.

## 1. 빠른 메뉴 (Quick Menu)
### 1.1 개념
어느 화면에서든 **한 번 탭**으로 여행 중 자주 쓰는 도구와 설정을 여는 바텀시트.
- 진입: 여행 상세 헤더 우측 **⚡ 버튼** + 앱 홈 헤더 우측 동일 버튼 (항상 같은 위치)
- 형태: 바텀시트 (절반 높이로 열림 → 위로 끌면 전체)
- 오프라인에서도 열림 (환율은 마지막 저장값 표시)

### 1.2 구성
```
┌──────────────────────────────────┐
│ ─── (핸들)                         │
│ 빠른 메뉴                           │
│                                    │
│ ┌ 💱 환율 ───────────────── › ┐    │  ← 탭하면 환율 계산기(전체 시트)
│ │ ¥100 = 912.34원              │    │
│ │ 수출입은행 · 10.22 11:02     │    │
│ └──────────────────────────────┘    │
│                                    │
│ ┌ ✨ AI 추천 ────────────── › ┐    │  ← 14번 문서, S-52
│ │ 신주쿠역 근처 지금 뜨는 곳      │    │
│ └──────────────────────────────┘    │
│                                    │
│ 바로가기                             │
│ [🛏 숙소로 길찾기] [🎫 예약번호]     │  ← 2열 그리드 큰 버튼
│ [📍 다음 일정]    [✅ 준비물]        │
│                                    │
│ 빠른 설정                            │
│ 화면      [라이트][다크][시스템]     │  ← 자주 바꾸는 3개만 바로 조절
│ 길찾기 앱  [네이버][구글][매번 묻기]  │
│ 이동수단   [대중교통][도보][자동차]   │
│                                    │
│ ⚙ 전체 설정                     ›  │  ← 설정 화면(S-23)
└──────────────────────────────────┘
```
| 영역 | 항목 | 동작 |
|---|---|---|
| 환율 카드 | 여행 국가 통화 ↔ 원화 미리보기 | 탭 → S-51 환율 계산기 |
| AI 추천 카드 | 기준 위치 이름 + "지금 뜨는 곳" | 탭 → S-52 AI 추천 (로그인 필요) |
| 바로가기 | 숙소로 길찾기 | 오늘 숙소 → 길찾기 시트 (숙소 없으면 숨김) |
| | 예약번호 | 이 여행 예약번호 목록, 탭하면 복사 |
| | 다음 일정 | S-12 상세 |
| | 준비물 | S-18 (여행 시작 전만 표시, 여행 중엔 "오늘 일정"으로 교체) |
| 빠른 설정 | 화면 테마 / 길찾기 앱 / 기본 이동수단 | 즉시 적용 |
| 전체 설정 | | S-23 |
- 여행 밖(앱 홈)에서 열면: 환율은 "마지막으로 본 통화" 또는 다가오는 여행 국가 통화, 바로가기는 숨김.

## 2. 환율 (조회 · 계산)
### 2.1 데이터 출처 — "네이버 환율 기준" 요구에 대한 결론
| 출처 | 공식 API | 갱신 | 판단 |
|---|---|---|---|
| 네이버 환율 (화면에 은행 고시 환율 표시) | ❌ 없음. 화면 수집(스크래핑)은 약관 위반 | 실시간에 가까움 | **데이터로 사용 불가 → "네이버에서 보기" 링크로 연결** |
| **한국수출입은행 현재환율 API** (`oapi.koreaexim.go.kr`, 공공데이터) | ✅ 무료, 인증키 | 영업일 1회 (11시경), 주말·공휴일·11시 전엔 값 없음 → 직전 영업일 값 사용 | **기본 데이터 (제안)**. 매매기준율·송금 받을 때/보낼 때 환율 제공 |
| 해외 무료 API (ECB 기반 등) | ✅ | 1일 1회 | 원화 기준 정확도 낮음 → 보조(수출입은행 미지원 통화용) ⚠️ |
| 유료 실시간 API | ✅ | 분 단위 | 비용 → 보류 |

→ **표시 방식 (제안)**
- 계산은 **수출입은행 매매기준율** 사용, 출처와 기준 시각을 항상 표시: `수출입은행 매매기준율 · 10.22 (수) 11:02`
- 계산기 하단 **[네이버 환율에서 실시간 확인 ›]** 버튼 → 네이버 검색 "엔화 환율" 등 외부 열기
- "실시간"이 아님을 명확히: 문구 "하루 한 번 갱신돼요. 환전 시에는 은행 환율을 확인하세요"
- ⚠️ 매매기준율과 실제 환전 환율(현찰 살 때)은 차이가 있음 → 옵션: "현찰 살 때(추정)" 표시 = 매매기준율 × (1 + 수수료율 1.75%) — 수수료율은 설정에서 조절 (§3 참고). 기본은 꺼짐 ⚠️

### 2.2 아키텍처
```
웹앱 ── GET /api/fx/latest ──▶ 홈 서버 ── (1일 1~2회 스케줄) ──▶ 수출입은행 API (인증키는 서버 .env)
  │        (로그인 불필요,          └ SQLite fx_rates 테이블에 저장, 응답은 Cloudflare 캐시 1시간
  │         개인정보 없음)
  └ IndexedDB settings.fxCache 에 마지막 값 저장 → 오프라인·서버 다운 시 사용
```
- 서버 스케줄: 평일 11:15, 14:00 재시도. 실패 시 직전 값 유지.
- 비로그인 사용자도 사용 가능 (공개 데이터). IP당 rate limit.
- 서버가 꺼져 있으면: 캐시값 + "10.21 기준 (최신 아님)" 회색 표시.

### 2.3 통화 단위 처리
- 수출입은행 응답의 `JPY(100)`, `IDR(100)` 처럼 **100단위 통화**를 파싱해 1단위로 정규화해서 저장, 화면에는 한국 관습대로 `¥100 = 912원` 표기.
- 원화 표시: 정수 반올림, 천 단위 콤마. 외화: 통화별 소수 자릿수(`Intl.NumberFormat`).
- 계산 값은 표시용이므로 저장하지 않음 → 부동소수점 이슈는 표시 반올림으로 충분 (가계부 제외라 정밀 금액 저장 없음).

### 2.4 S-51 환율 계산기 화면
```
┌──────────────────────────────────┐
│ ←  환율 계산기                     │
│                                    │
│ 🇯🇵 일본 엔 JPY ▾                   │
│ ┌──────────────────────────────┐  │
│ │                     ¥ 3,500 │  │  ← 입력 중인 칸 (파란 테두리)
│ └──────────────────────────────┘  │
│              ⇅                     │  ← 탭하면 위아래 통화 전환
│ 🇰🇷 대한민국 원 KRW                  │
│ ┌──────────────────────────────┐  │
│ │                    31,932원  │  │
│ └──────────────────────────────┘  │
│ [¥1,000] [¥5,000] [¥10,000] [¥50,000]│  ← 빠른 금액 칩 (통화별 자동)
│                                    │
│ ¥100 = 912.34원                    │
│ 수출입은행 매매기준율 · 10.22 11:02   │
│ [네이버 환율에서 실시간 확인 ›]       │
│                                    │
│ ┌────┬────┬────┐                  │
│ │ 1  │ 2  │ 3  │                  │  ← 앱 내 숫자 키패드 (큰 버튼 64px)
│ │ 4  │ 5  │ 6  │                  │    × ÷ 없이 단순 입력 (P1: 사칙연산)
│ │ 7  │ 8  │ 9  │                  │
│ │ 00 │ 0  │ ⌫  │                  │
│ └────┴────┴────┘                  │
└──────────────────────────────────┘
```
- **입력 방식**: 앱 내 숫자 키패드 (시스템 키보드보다 크고 빠름, 소수점 필요한 통화는 `00` 대신 `.`)
- 입력 즉시 계산 (버튼 없음), 길게 누르면 ⌫ 전체 삭제
- 통화 선택: 여행 국가 통화 자동, ▾ 탭 → 검색 가능한 통화 목록 (최근 사용 3개 상단)
- 여러 통화 여행(예: 유럽 여러 나라)은 상단 통화 칩으로 전환
- 값 탭 → 복사
- 우선: **P1** (빠른 메뉴와 함께)

### 2.5 여행 화면 속 환율 표시 (선택)
- 장소 카드의 가격대(₩₩)에는 환율 적용하지 않음 (Google 가격대는 상대 등급)
- 일정/예약 메모에 적힌 금액은 자동 변환하지 않음 (단순함 유지)

## 3. 설정 (Settings)
### 3.1 컨트롤 선택 원칙 (UI 일관성 규칙)
| 설정 성격 | 컨트롤 | 이유 | 예 |
|---|---|---|---|
| 켜기/끄기 | **토글 스위치** | 한 번 탭, 상태가 바로 보임 | 자동 동기화 |
| 2~4개 중 하나 (짧은 라벨) | **세그먼트 버튼** (가로 버튼 묶음) | 모든 선택지가 한눈에, 한 번 탭 | 테마, 시간 표기 |
| 5개 이상 중 하나 / 설명이 필요한 선택 | **라디오 목록** (아이콘+설명) | 세로로 읽기 쉬움 | 기본 길찾기 앱, 언어 |
| 정해진 간격의 작은 숫자 | **스테퍼 (− 값 +)** | 정확한 값, 오입력 없음 | 백업 알림 주기(일), 시간 입력 간격 |
| 연속 범위 + 감각적 조절 | **슬라이더 + 현재 값 표시** | 드래그로 빠르게, 미리보기 | 글자 크기, 검색 반경 |
| 자유 숫자 | **숫자 입력 (숫자 키패드, 단위 접미사)** | 임의 값 | 환전 수수료율 % |
| 목록에서 고르기(많음) | **선택 시트 (검색 포함)** | 긴 목록 | 기준 통화 |
- 모든 설정은 **즉시 적용, 저장 버튼 없음**. 변경 시 화면 하단 토스트 없음(조용히), 단 되돌리기 어려운 것(데이터 삭제)만 확인.
- 각 섹션 하단 `기본값으로 되돌리기` (텍스트 버튼).
- 비활성 항목은 숨기지 말고 회색 + 이유 표시 (예: "로그인하면 사용할 수 있어요").
- 라벨은 왼쪽, 컨트롤은 오른쪽(토글·스테퍼) 또는 라벨 아래 전체 폭(세그먼트·슬라이더·라디오).

### 3.3 S-23 설정 화면 레이아웃

```
└──────────────────────────────────┘
```

### 3.4 저장 · 동기화 규칙
- 설정은 `AppSetting` (IndexedDB key-value)에 저장.
- **기기별 설정**(테마, 글자 크기, 진동, 내 위치)은 동기화하지 않음.
- **계정 설정**(길찾기 앱, 이동수단, 장소 필터 기본값, 환율 수수료, 시간 표기)은 로그인 시 서버 동기화 ⚠️ (H 항목 결정).
- Zod 스키마로 범위 검증 (예: 반경 0.5~20) → 잘못된 값은 기본값으로 복구.
