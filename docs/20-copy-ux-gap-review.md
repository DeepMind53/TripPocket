# 20. 문구 정리 · UX/UI 추가 개선 · 빠진 기능 점검 (제안 — 사용자 확인 전 적용 금지)

> 2026-10-25 사용자 요청: "문구의 '.' 부분은 줄바꿈, 내용은 간략하게. UX/UI 개선 더 찾고, 여행 앱에 꼭 필요한데 빠진 것 점검. 바로 적용하지 말고 설계 먼저."
> 결정이 필요한 것은 §5.

## 1. 문구 정리

### 1.1 규칙 (CLAUDE.md·docs/11에 추가 제안)

1. **한 줄 = 한 문장.** 문장이 둘 이상이면 "." 자리에서 줄을 바꾼다 (`\n`). 줄 끝 마침표는 뺀다
2. **한 줄은 휴대폰 한 줄(약 22자) 안쪽**을 목표로. 넘으면 줄이거나 나눈다
3. **무엇이 됐는지 → 할 일** 순서. 이유·배경은 꼭 필요할 때만
4. 버튼은 동사로 짧게 ("다시 시도", "직접 입력"), 안내문은 "~해요"체로 통일
5. 같은 뜻은 같은 말로 (예: "올려요/동기화해요" → "동기화해요", "지우기/삭제" → 화면별 통일표)

### 1.2 대상 — 지금 문구 1,017개 중 약 80개

두 문장 이상이 한 줄에 붙어 있거나 긴 것 (자동 검사로 뽑음):
로그인·탈퇴·동기화 선택, 백업·복원 오류, 예약 불러오기 실패, 준비 템플릿 안내, 지도 오프라인·일시 정지, AI 추천 안내·실패, 공유·초대, 관리자·API 사용량 설명, 후기 안내 등

예시:

| 지금 | 바꾼 뒤 |
|---|---|
| 이 편명의 최근 운항 정보를 찾지 못했어요. 직접 입력해 주세요. | 운항 정보를 못 찾았어요<br>직접 입력해 주세요 |
| 지도는 인터넷에 연결되면 보여요. 일정과 길찾기는 그대로 쓸 수 있어요 | 지도는 온라인에서 보여요<br>일정·길찾기는 그대로 돼요 |
| {{n}}개를 넣었어요. 저장을 눌러야 반영돼요 | {{n}}개를 넣었어요<br>[저장]을 눌러 주세요 |
| 주소가 없어요. 편집에서 추가할 수 있어요. | 주소가 없어요<br>편집에서 넣을 수 있어요 |

### 1.3 화면 쪽 손볼 것

- **토스트(아래 알림)가 줄바꿈을 그리지 않는다** (`Toaster`에 `whitespace-pre-line` 없음) → 같이 고친다
- 줄을 바꾼 문구가 들어가는 칸 중 줄바꿈 표시가 빠진 곳 점검 (시트 설명·빈 화면·카드 보조문)
- **자동 검사 추가**: 한 문구에 "요. "·"다. "가 있으면 테스트 실패 → 앞으로 새 문구도 규칙대로

## 2. UX/UI 추가 개선 후보

우선순위: ★★★ 바로 체감 · ★★ 있으면 좋음 · ★ 나중

| # | 개선 | 이유 | 우선 |
|---|---|---|---|
| U1 | **일정 상세 시트 정리** — 머리글에 후기·방문 시간이 함께 있어 붐빔 → 방문 시간은 정보 줄 첫 칸으로, 후기 버튼만 오른쪽 | 버튼·입력이 겹쳐 보임 | ★★★ |
| U2 | **오늘 화면(여행 중)** — 홈 맨 위에 "지금·다음 일정" 카드 (시간·장소·[길찾기]) | 여행 중 가장 많이 하는 동작이 2~3번 눌러야 함 | ★★★ |
| U3 | **홈 준비 현황 접기** — 칸이 5개 + AI 버튼으로 길어짐 → 2줄 요약, 눌러서 펼치기 | 첫 화면이 길다 | ★★ |
| U4 | **예약 폼 단계화** — 종류 고르기 → 필요한 칸만 (지금도 종류별이지만 한 화면이 김) | 입력칸이 많아 아래 버튼까지 멀다 | ★★ |
| U5 | **빈 화면에 다음 행동** — 일정·예약·저장이 비었을 때 버튼 1개씩 (샘플·추천·검색) | 처음 쓰는 사람이 멈춤 | ★★ |
| U6 | **스크롤 위치 기억** — 일정 상세 닫거나 다른 탭 갔다 오면 보던 날짜로 | 긴 여행에서 다시 찾기 번거로움 | ★★ |
| U7 | **누를 수 있는 크기 점검** — 44px 미만 버튼(별점·작은 링크) 정리 | 오탭 | ★★ |
| U8 | **오프라인 표시 일관성** — 지도·검색·후기·환율이 각자 다른 문구 → 공통 부품 하나 | 일관성 | ★ |
| U9 | **큰 글씨 설정에서 줄넘침 점검** — 글자 크기 120~130%에서 칩·탭 줄바꿈 | 접근성 | ★ |

## 3. 여행 앱에 꼭 필요한데 빠진 것

다른 여행 앱(트리플·마이리얼트립·Wanderlog·TripIt)과 비교. 무료로 가능한지 함께 적었다.

| # | 기능 | 지금 | 제안 | 비용 |
|---|---|---|---|---|
| G1 | **알림** — 출발 D-1, 입국신고 낼 때(TDAC 3일 전 등), 체크인·일정 시작 30분 전 | 없음 | 웹 푸시(PWA) — 홈 서버에서 보냄 | 무료 (VAPID 키, 새 의존성 1개 검토) |
| G2 | **예약 문서 보관** — 이티켓·바우처 PDF·사진을 예약에 붙여 오프라인에서 보기 | 없음 | 기기에 저장(IndexedDB), 원하면 동기화 | 무료 (홈 서버 용량만) |
