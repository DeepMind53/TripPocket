## 2. 디자인 원칙
1. **여행 중 3초 규칙** — 앱을 열고 3초 안에 "다음 일정·주소·예약번호"를 볼 수 있어야 한다.
2. **한 손 엄지 영역** — 주요 버튼은 화면 하단 1/3. 상단은 정보, 하단은 행동.
3. **지도와 목록은 한 화면에** — 일정은 지도(위) + 목록(아래 시트)로 동시에 본다. 목록을 끌어올리면 지도가 접힌다.
4. **편집은 가볍게, 실수는 되돌리게** — 확인 팝업 대신 "실행 취소" 스낵바.
5. **조용한 화면** — 광고·추천 콘텐츠 없음. 강조색은 화면당 1~2곳.
6. **오프라인을 숨기지 않되 겁주지 않기** — 동기화 상태는 작은 아이콘으로만.

## 4. 타이포그래피
- 폰트: **Pretendard Variable** (한글 가독성, 숫자 폭 균일) — 셀프 호스팅, 한글 2,350자 + 영문 서브셋 ⚠️
- 숫자(시간·거리)에는 `font-variant-numeric: tabular-nums` (자릿수 정렬)
- 한국어 줄바꿈: `word-break: keep-all; overflow-wrap: anywhere;`

| 토큰 | 크기/행간 | 굵기 | 용도 |
|---|---|---|---|
| `display` | 28/36 | 700 | 여행 만들기 질문 제목 |
| `title-1` | 22/30 | 700 | 화면 제목 |
| `title-2` | 18/26 | 600 | 섹션 제목, Day 헤더 |
| `body-1` | 16/24 | 500 | 카드 제목, 입력값 |
| `body-2` | 15/22 | 400 | 본문 |
| `caption` | 13/18 | 400 | 주소, 보조 정보 |
| `micro` | 11/14 | 600 | 배지, 핀 숫자 |
- 입력창 글자 **16px 이상** (iOS 자동 확대 방지). 시스템 글자 크기 설정을 따르도록 `rem` 사용.

## 8. 모션
- 기본 지속 시간 200ms, 시트 280ms, `cubic-bezier(.2,.8,.2,1)`
- 드래그 중 카드 확대 1.02 + 그림자, 놓을 때 햅틱(`navigator.vibrate(10)` 지원 시)
- `prefers-reduced-motion` 이면 모든 전환을 페이드로 대체

## 9. 한국어 문구(UX Writing) 가이드
| 원칙 | 좋은 예 | 피할 예 |
|---|---|---|
| 해요체, 짧게 | "일정을 추가했어요" | "일정이 성공적으로 추가되었습니다." |

## 10. 접근성
- 명도 대비: 본문 4.5:1, 큰 글자·아이콘 3:1 이상 (토큰 확정 시 검사 스크립트로 확인)
- 색만으로 의미 전달 금지 (Day 핀 = 색 + 숫자, 상태 = 색 + 아이콘 + 글자)
- 모든 드래그 동작에 대체 수단 ("다른 날로 이동", "위로/아래로" 메뉴)
- 스크린리더 라벨 한국어, 포커스 순서 = 시각 순서
- 시스템 글자 크기 200%에서 레이아웃 깨짐 없음

## 11. 다크 모드
- 시스템 설정 따름 + 설정에서 수동 선택 (라이트 / 다크 / 시스템)
- 지도는 제공자의 다크 스타일 사용 가능 여부 확인 ⚠️ (네이버/구글 각각)
