# 02. 유사 앱 벤치마크

조사 기준: 2026년 기준 일반적으로 알려진 기능 위주 (세부 사항은 버전에 따라 다를 수 있음).

## 1. 비교 대상 요약
| 앱 | 강점 | 약점 (우리 관점) | 차용할 점 |
|---|---|---|---|
| **TripIt** | 예약 확인 메일 포워딩 → 자동 일정 생성, 깔끔한 타임라인 | 계정 필수, 유료 기능 많음, 계획(위시리스트) 기능 약함 | 예약 중심 타임라인, 항공/숙소 카드 디자인 |
| **Wanderlog** | 지도+일정 동시 보기, 장소 드래그, 공동 편집 | 계정 필수, 오프라인은 유료, 무거움 | 지도/리스트 분할 뷰, 위시리스트→날짜 배치 |
| **Google 지도 (저장 목록)** | 장소 데이터 풍부, 리스트 저장 | 일정(시간/날짜) 개념 없음 | "지도 앱으로 열기" 딥링크 |
| **트리플 / 마이리얼트립** (국내) | 한국어 콘텐츠, 일정 짜기 UI, 도시 가이드 | 커머스 유도, 계정 필수 | Day 탭 + 카드형 일정 UI, 한국 사용자 친화 용어 |
| **Notion 여행 템플릿** | 자유도 최고, 표/보드/캘린더 뷰 | 모바일에서 편집 불편, 여행 특화 기능 없음 | 다중 뷰(리스트/타임라인/지도), 자유 메모 |
| **PackPoint / Packr** | 날씨·여행 유형 기반 준비물 추천 | 단일 기능 | 준비물 템플릿 + 카테고리 |
| **Polarsteps** | 여행 기록/회고, 경로 시각화 | 계획보다 기록 중심 | 여행 후 회고(사진/경로) — P2 아이디어 |

## 2. 시장 공백 (우리 포지셔닝)
```
            계정 필요 ◀──────────────▶ 계정 불필요
  기능 풍부  TripIt, Wanderlog,        ┌──────────────┐
     ▲       트리플                    │   ★ 우리 앱   │
     │                                 └──────────────┘
  단일 기능  PackPoint                 메모장, 엑셀
```
→ **"계정 없이, 오프라인에서, 일정·예약·준비물·지도를 통합"** 하는 앱이 드물다.

## 3. 차용할 UX 패턴 (구체)
1. **Day 탭 + 세로 카드 리스트** (트리플, Wanderlog) — 모바일에서 가장 익숙한 형태
2. **숙소는 매일 하단에 고정 표시** (Wanderlog) — "오늘 어디서 자지?" 즉시 확인
3. **항공권은 탑승권 스타일 카드** (TripIt) — 편명, 시간, 게이트 강조
4. **위시리스트(장소함) → 드래그로 날짜 배치** (Wanderlog)
5. **"오늘" 홈** — 진행 중 여행이면 앱을 열자마자 오늘 일정 + 다음 일정 카운트다운
6. ~~경비 정산~~ — 가계부 제외 결정(2026-10-22)으로 삭제
7. **준비물 템플릿 체크** (PackPoint) — 카테고리별 접기/펼치기, 진행률 바
8. **길찾기 버튼** — 앱 내 지도 대신 사용자가 쓰는 지도 앱으로 딥링크 (구현 비용↓, 정확도↑)

## 4. 의식적으로 피할 것
- 첫 화면 회원가입/온보딩 3페이지 이상
- 추천 콘텐츠/광고로 일정 화면 가리기
- 지도 API 의존으로 오프라인에서 빈 화면
