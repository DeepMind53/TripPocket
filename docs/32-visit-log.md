# 32. 방문 기록 화면 (여행별·도시별·장소별)

2026-11-24 사용자 요청: 기록 탭의 방문 기록이 모두 펼쳐져 있어 보기 어렵다. 여행별·도시별로 보고, 관리·검색하기 쉽게.
사용자 결정 (같은 날): ① 바로 정식 ② 보기 3가지 모두 ③ 기록 탭엔 요약 칸 ④ 새 문구는 구현 때 확인.

## 1. 기록 탭 요약 칸 (`records/VisitSummary.tsx`)

- 합계 한 줄: "방문 N · 미방문 N · 도시 N곳"
- 최근 여행 3줄 (국기·제목·시작일·방문 n/전체). 누르면 `/records/visits?trip=<id>` — 그 여행을 펼친 채로
- [전체 보기] → `/records/visits`

## 2. 전용 화면 `/records/visits` (`records/VisitLogPage.tsx`, 지연 로딩)

- 위에서부터: 검색칸 → [여행별|도시별|장소별] → 고르기 칩(전체·방문·미방문·기록에 있는 종류만) → 합계
- 보기·검색·고르기는 주소(`?view=&q=&f=`)에 남긴다 — 상세 시트를 닫거나 일정에 다녀와도 그대로
- 묶음은 접고 편다. 처음엔 맨 위 하나만 펼침(보기마다 따로), 검색 중엔 모두 펼침
- 여행별: 최근 여행 먼저 → 날짜별(일차 색 점 + "10.23 (금) 1일차")
- 도시별: 방문 많은 도시 먼저, 여러 여행의 같은 도시는 한 칸, 모르는 곳은 "기타 지역"으로 맨 끝
- 장소별(다시 간 곳): `samePlace`(Google id, 또는 이름 같고 300m 안)로 합침. 방문 많은 곳 먼저, 방문이 없으면 "미방문"

## 3. 도시 정하기 (`domain/visitLog.ts` `visitCity`, 스키마 변경 없음)

1. 목적지 도시(나라 제외)가 하나면 그곳
2. 일정 좌표에서 가장 가까운 목적지 도시 (80km 안)
3. 주소·장소 이름에 도시 이름이 나오는 곳
4. 모르면 null → "기타 지역"

서버·외부 API 호출 없음, 위치 저장 없음.

## 4. 검색

장소 이름·주소·메모·여행 제목·도시 이름. 초성만 치면 초성으로 (`tripSearch`와 같은 `normalize`·`choseong`).
결과가 없으면 "찾는 장소가 없어요" + [검색 지우기](검색·고르기 모두 풀기).

## 5. 줄을 누르면 상세 시트 (`records/VisitItemSheet.tsx`)

- [미방문][방문] — 일정 화면과 같은 `applyVisit` (미방문은 저장 탭에도)
- [일정에서 보기] → 그 여행의 그날 일정 화면
- [저장 탭에 담기] — 방문한 곳도 담을 수 있게 (`saveSkippedPlace`, 이미 있으면 "이미 저장한 곳이에요")
- 사진(`ItemPhotos`), 길찾기(`DirectionsPanel`)
- 여러 개 한 번에 바꾸기는 넣지 않음 (쓸 일이 드물고 화면만 복잡)
