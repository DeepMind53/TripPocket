# 28. 숙소 최저가 비교 — 설계 제안

- 상태: **제안** (사용자 확인 전 구현하지 않음)
- 날짜: 2026-11-09
- 요청: 숙소 이름·체크인·체크아웃을 넣고 검색하면 국내외 숙소 예약 앱 3곳 이상(아고다·트립닷컴·여기어때·NOL 등)의
  가격을 한 번에 비교해서 보여 준다. 참고: 아고다스캐너(https://agodascanner.com).
  무료 API 또는 직접 검색 방식 가능. **무한 검색 요청이 생기지 않도록 방어 코드와 오류 시 검색 중단은 필수**

## 1. 참고한 것 — 아고다스캐너는 어떻게 하나
- 입력: 아고다 숙소 링크 하나. 출력: 같은 숙소의 "경로별" 가격 비교
- 방식(사이트 설명 기준): 아고다 링크의 **접속 경로 값(CID)** 을 구글 지도·카드사·항공사 등 23가지로 바꿔
  아고다에 각각 물어본다 → 한 번 검색에 아고다 요청 23번. 즉 **아고다 한 곳의 경로별 할인 비교**이고,
  여러 예약 앱을 비교하는 것은 아니다. 가격을 받는 방법(페이지 수집)은 공개돼 있지 않다
- 우리 요청은 "여러 예약 앱 비교"라서 방식이 다르다. 아고다 경로 비교는 아래 선택지 E로 따로 둔다

## 2. 가격을 얻는 방법 — 선택지

| | 방식 | 가격을 앱에 보여 줌 | 비용 | 위험 |
|---|---|---|---|---|
| **A** | **바로 검색 링크**: 숙소 이름·날짜·인원을 넣은 각 예약 앱 검색 주소를 만들어 [아고다][트립닷컴][부킹닷컴][여기어때][NOL][구글 호텔] 버튼으로 연다 | ✗ (누르면 각 앱에서 가격 확인) | 무료, API 호출 0 | 거의 없음 (주소 모양이 바뀌면 검색 화면만 열림) |
| **B** | **구글 호텔 가격 (SerpApi `google_hotels`)**: 한 번 검색에 구글 호텔이 모은 예약처별 가격(부킹닷컴·아고다·트립닷컴·호텔스닷컴 등)을 받는다 | ○ 예약처별 1박 가격·최저가 | **월 250회 무료**(시간당 50), 넘으면 유료 $25/월~ | 국내 앱(여기어때·NOL)은 구글 호텔에 없을 수 있음. 실제 응답에 예약처별 가격이 오는지 **활용 전 실제 호출로 확인 필요** |
| **C** | **공식 제휴 API**: 아고다 제휴(Affiliate Search API), 부킹닷컴 Demand API, 트립닷컴 제휴 | ○ | 가입 무료인 곳도 있으나 **승인 심사**·표시 조건·제휴 링크 의무 | 개인 앱은 승인이 어려움. 여기어때·NOL은 공개 API 없음 |
| **D** | **직접 수집(스크래핑)**: 서버가 각 예약 사이트 검색 페이지를 받아 가격을 읽는다 | ○ | 무료 | **이용약관 위반 소지**, 홈 PC IP 차단, 사이트가 바뀌면 바로 고장, 봇 차단(CAPTCHA) — 비추천 |
| **E** | **아고다 경로 비교(아고다스캐너 방식)** | ○ (아고다 한 곳) | 무료 | D와 같은 위험 + 한 번에 아고다 요청 수십 번 → 비추천 |

### 추천
- **1단계 A (바로 검색 링크)** — 무료·안전·오프라인에서도 버튼은 보임. 국내 앱(여기어때·NOL) 포함 가능
- **2단계 B (구글 호텔 가격)** — 무료 월 250회 안에서만, 넘으면 자동 중지(과금 없음). 가격이 오는 예약처만 표로,
  나머지(여기어때·NOL 등)는 A의 링크 버튼으로
- C는 나중에 승인되면 B 대신·함께. D·E는 하지 않는다

## 3. 화면 (안) — 실험실 "숙소 최저가"
```
┌ 숙소 최저가 찾기 ─────────────────────────┐
│ 숙소 이름 [신주쿠 그레이스리 호텔        ]  │  ← 예약 탭 숙소에서 열면 이름·날짜가 채워짐
│ 체크인 [11.24 (화)]  체크아웃 [11.27 (금)] │
│ 인원 [2]                                   │
│ [       최저가 검색       ]                │  ← 누를 때만 (자동 검색 없음)
├───────────────────────────────────────────┤
│ 1박 최저 ₩128,000 · 부킹닷컴               │  ← B: 가격 낮은 순
│  부킹닷컴   ₩128,000  [열기]               │
│  아고다     ₩131,500  [열기]               │
│  트립닷컴   ₩135,200  [열기]               │
│ 11.09 14:02 기준 · 세금·수수료는 앱마다 달라요 │
├───────────────────────────────────────────┤
│ 다른 앱에서 바로 찾기                       │  ← A: 늘 보임
│ [여기어때] [NOL] [아고다] [트립닷컴] [구글]  │
└───────────────────────────────────────────┘
```
- 여는 곳: 예약 탭 숙소 카드 [최저가 비교], 예약 추가(숙소) 시트, 빠른 메뉴 바로가기 후보
- 가격은 **저장하지 않는다**(평점·리뷰처럼 바뀌는 값, 6시간 캐시만). 예약 금액 저장 금지 규칙과도 맞음

## 4. 무한 검색 방지 · 오류 시 중단 (필수)
| 층 | 방어 |
|---|---|
| 화면 | 버튼을 누를 때만 검색 (입력·화면 열기로 자동 검색 없음). 검색 중에는 버튼 잠금, 같은 조건 재검색은 결과 재사용 |
| 화면 | 자동 재시도 없음. 실패하면 "잠시 뒤 다시"만 보여 주고 멈춤. 1분에 3번 넘게 누르면 잠깐 막음 |
| 화면 | 요청마다 시간 제한 10초 + 화면을 나가면 요청 취소(AbortController) |
| 서버 | 로그인 필수, 사람마다 **분당 3회·하루 30회** 제한(rate limit) |
| 서버 | 같은 숙소·날짜·인원은 **6시간 캐시** — 무료량 아끼기, 동시에 같은 요청이 오면 하나로 합침 |
| 서버 | `guardApi`·`trackApi` (새 API `serpapi_hotels` 등록: 월 250회, 95%에서 자동 중지) |
| 서버 | **연속 실패 3번이면 30분 동안 검색 중단**(차단기) → 관리자 API 사용량 화면에 표시 |
| 서버 | 외부 응답 시간 제한 8초, 응답 크기 상한, 이상한 응답(숫자 아님·통화 없음)은 버림 |
| 공통 | 한 번 검색에 외부 호출 **최대 2번**(숙소 찾기 1 + 가격 1). 반복문으로 페이지를 넘기지 않음 |

## 5. 보내는 정보·규칙
- 보내는 것: 숙소 이름, 체크인·체크아웃 날짜, 인원, 통화(KRW)뿐. 사용자 정보·위치 좌표는 보내지 않는다
- 서버 → SerpApi(구글 호텔)로만. 키는 서버 `.env`(`SERPAPI_KEY`), 웹 번들에 넣지 않는다
- ADR-0004(외부 API 범위)에 "숙소 가격 조회"를 넣는 **새 ADR 필요**
- 개인정보 처리방침·데이터 출처에 SerpApi(구글 호텔) 추가
- 가격 옆에 출처·기준 시각·"앱에서 최종 가격 확인" 문구. 예약은 각 앱에서

## 7. 단계
1. A 바로 검색 링크 (실험실) + 방어 코드 틀(화면 쪽)
2. B 서버 프록시 `/api/lodging/prices` + 캐시·한도·차단기 + 화면 가격 표 — **SerpApi 키 발급 후 실제 응답 확인**
3. (선택) C 제휴 승인되면 교체·추가
