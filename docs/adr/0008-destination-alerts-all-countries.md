# ADR-0008: 여행지 기상·재난 특보 — 모든 여행 나라에 공식 출처로

- 상태: 확정
- 날짜: 2026-10-27

## 배경 (Context)
사용자 요청(2026-10-26): 태풍·지진·호우 특보 등 여행 가는 나라의 특이사항을 보여 주기. 설계는 `docs/24-weather-disaster-alerts.md`.
사용자 결정(2026-10-27): §6의 A1–A4 **모두 적용**, **여행 가는 나라마다 빠짐없이** 반영.

## 결정 (Decision)
1. **전 세계 공통(모든 나라)**: GDACS(태풍·지진·홍수·화산) + USGS(지진) + 외교부 여행경보·특별여행주의보 — 내용을 보여 준다
2. **나라별 기상청 특보**: 약관이 다시 보여 주기를 허락하고 무료인 곳은 내용을 보여 준다 (docs/24 §7 표)
3. **그 밖의 나라**(약관이 막혔거나 공개 API가 없는 곳): 그 나라 기상청 특보 페이지 공식 링크 + WMO 세계 악기상 정보 센터 링크 — 내용을 옮기지 않는다
4. 빨강 등급(또는 기상청 "경보")이 새로 생기면 푸시 1번 (여행 1개당 하루 1번까지)
5. 모두 무료. 키가 필요한 곳(공공데이터포털·대만 CWA)은 서버 `.env`에만, 웹 번들에 넣지 않는다. 모든 호출은 `guardApi`·`trackApi`
6. 사용자 현재 위치는 보내지 않는다. 지역별로 발표하는 일본·미국·캐나다만 목적지 도시 좌표를 약 10km로 줄여 보낸다 (2026-10-27 구현 때 보완)

## 검토한 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| GDACS·USGS·외교부만 | 단순 | 호우·대설 같은 일상 특보가 빠짐 |
| WMO 등록 CAP 피드를 전부 그대로 보여 주기 | 135개 나라 한 번에 | 나라마다 약관이 달라(재배포 금지 포함) 확인 안 된 곳은 쓸 수 없음 |
| 유료 통합 API | 품질·형식 통일 | 무료 원칙(L 그룹)에 어긋남 |

## 결과 (Consequences)
- 좋아지는 점: 어느 나라로 가든 최소한 세계 재난·외교부 경보 + 그 나라 공식 특보 링크가 보인다
- 감수하는 점: 나라별 내용 표시는 약관 확인된 곳부터 늘어난다. 원문 언어 그대로(종류명만 한국어). 일본 기상업무법에 따라 자체 판단 문구 없이 출처와 함께 옮기기만
- ADR-0004 외부 API 범위에 docs/24 §7 출처를 더한다
