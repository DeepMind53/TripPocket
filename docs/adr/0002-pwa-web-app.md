# ADR-0002: 웹 기반 PWA로 제공

- 상태: 확정 (사용자 요구사항)
- 날짜: 2026-10-22

## 배경
앱스토어 심사·설치 없이 누구나 링크로 바로 쓰게 하고 싶다. 여행 중에는 오프라인 동작이 필수다.

## 결정
- 정적 SPA + Service Worker 기반 **PWA**로 만든다.
- 홈 화면 설치를 적극 권장한다 (iOS에서 저장 데이터 보존에 유리).
- 정적 호스팅(HTTPS)에 배포한다.

## 검토한 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| 네이티브 앱 (Flutter/RN) | 저장 안정성, 푸시 | 스토어 배포·심사, 개발비 |
| 일반 웹사이트(SW 없음) | 단순 | 오프라인 불가 |

## 결과
- 좋아지는 점: 링크 하나로 배포, 업데이트 즉시 반영.
- 감수하는 점: iOS 웹 저장소 정책 영향, 백그라운드 알림 제한(iOS 16.4+ 설치 시 웹 푸시 가능하나 서버 필요 → 미사용).
- 후속 작업: 필요 시 Capacitor로 네이티브 포장 가능하도록 브라우저 API를 어댑터로 격리.
