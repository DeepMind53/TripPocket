# ADR-0011: 디자인 개편 "여행 노선" — 모양만 바꾸고 기능은 그대로

- 상태: 확정 (구현 전)
- 날짜: 2026-11-09
- 설계: `docs/29-design-renewal.md`

## 배경 (Context)
1·2차 unslop 정리(`11` §13) 뒤에도 화면마다 카드·목록이 비슷해 여행 앱의 얼굴이 약했다.
사용자 요청(2026-11-09): "기능은 삭제·변경 없이 디자인만 바꾼다. 기존 기능을 모두 포함하고 편하게 쓰는 방향으로. 설계 문서를 먼저 아주 자세하게."
지난 제안 가운데 노선도(일정) + 탑승권(예약)을 골랐고, 지도 우선(B)은 이번 범위에서 뺐다.

## 결정 (Decision)
- 콘셉트 "여행 노선": 하루 = 일차 색 노선, 장소 = 역, 이동 = 환승 표시(거리만), 이동 예약 = 탑승권, 지난 여행 = 여권 도장
- 기능·설정·데이터·문구 키·화면 사이 이동은 바꾸지 않는다. 같은 화면 안 순서는 설계 문서 §7에 적은 것만 옮긴다
- 홈 여행 중: 다음 역 카드(파랑 채움)가 첫 자리, 큰 여행 카드는 한 줄 띠
- 고정폭 글꼴 파일 1개 추가: JetBrains Mono(OFL 1.1) 500 굵기를 숫자·영문·기호만 남긴 woff2(약 15KB), 셀프 호스팅 — CLAUDE.md "새 의존성은 묻는다"에 따른 사용자 결정
- 외부 디자인 스킬(frontend-design·ui-ux-pro-max·Impeccable)을 구현 1단계 때 `.claude/skills/`에 설치 — 설치 전에 받을 곳·크기를 알리고 스크립트는 읽은 뒤 실행
- 우선순위: 사용자 결정 > `docs/29` > `11` §13 unslop > 다른 스킬

## 결과 (Consequences)
- 좋은 점: 화면 생김새가 하는 일을 말하고, 여행 중 다음 장소·남은 시간·길찾기가 첫 화면 위쪽에 온다
- 비용: 첫 화면 받는 양 +15KB(글꼴) + JS 약 +5KB 안쪽 목표. 테스트의 접근 이름은 유지해야 한다
- 이동 시간 어림은 하지 않는다 (틀린 시간을 보여 주지 않기). 서버 요청 수는 그대로
