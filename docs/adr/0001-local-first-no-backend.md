# ADR-0001: 서버 없는 로컬 우선 저장

- 상태: 부분 대체됨 → [ADR-0003](0003-home-pc-sync-server.md) (오프라인 우선·로컬 1차 저장은 유지, 선택적 로그인 동기화 추가)
- 날짜: 2026-10-22

## 배경
누구나 계정 없이 쓸 수 있어야 하고, 데이터는 각자 휴대폰에 저장하기를 원한다.
서버 운영비·개인정보 관리 부담 없이 배포하고 싶다.

## 결정
- 백엔드/데이터베이스 서버를 두지 않는다.
- 모든 사용자 데이터는 브라우저 IndexedDB에 저장한다 (Dexie 사용 예정, B3에서 확정).
- 기기 간 이동·공유는 **파일/링크 기반 내보내기·가져오기**로 해결한다.

## 검토한 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| Firebase/Supabase + 계정 | 동기화·공동 편집 | 운영비, 개인정보 책임, 가입 장벽 |
| 로컬 + 선택적 클라우드 | 유연 | 초기 복잡도 ↑ → P2로 연기 |

## 결과
- 좋아지는 점: 운영비 0, 오프라인 완전 동작, 개인정보 위험 최소.
- 감수하는 점: 데이터 유실 위험 → `06-storage-backup-sharing.md`의 대응책을 MVP(M2)에 반드시 포함.
  실시간 공동 편집 불가.
- 후속 작업: 모든 엔티티에 `updatedAt`/`deletedAt` 포함해 향후 병합 가능하게 설계.
