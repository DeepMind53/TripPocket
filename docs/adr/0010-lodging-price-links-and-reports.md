# ADR-0010: 숙소 가격 — 눌러서 확인하는 링크 + 사용자 가격 기록 (30일 공유)

- 상태: 확정
- 날짜: 2026-11-09
- 설계: `docs/28-lodging-price-compare.md`

## 배경 (Context)
사용자 요청(2026-11-09): 숙소 이름·체크인·체크아웃으로 여러 예약 앱 가격을 한 번에 비교한다. 아고다스캐너처럼.
무한 요청을 막는 방어 코드와 오류 시 중단은 필수.
아고다스캐너는 가격을 가져오지 않고 아고다 링크의 접속 경로 값(CID)만 바꾼 링크 23개를 만든다 (페이지 코드 확인).
CLAUDE.md는 사용자 데이터를 ADR-0004 범위 밖으로 보내지 못하게 하고, 가계부(지출 기록)를 범위에서 뺐다 → 이 ADR로 범위를 정한다.

사용자 결정(2026-11-09, 설계 문서 §13 Q1~Q10):
- 가격은 사용자가 링크를 눌러 각 앱에서 확인한다. 아고다 경로 수는 제한하지 않는다
- 본 가격을 사용자가 적고, 본 날짜와 함께 서버에 30일 보관해 로그인한 모두가 목록으로 본다 (작성자 비공개, 본 시각은 날짜만)
- 구글 호텔(SerpApi) 참고 가격은 링크·기록 다음 단계에 넣는다. 무료량을 넘으면 자동 중지 + 구글 호텔 창 열기
- 예약 앱 페이지를 서버가 직접 읽는 방식(직접 수집)은 하지 않는다

## 결정 (Decision)
1. **링크는 웹에서 만든다 (요청 0).** 앱별 검색 링크 6개와 아고다 경로별 링크(CID만 바꿈). 제휴 태그·추적 값은 넣지 않는다
2. **아고다 숙소 자동 찾기:** 아고다 링크가 없을 때만 서버가 아고다 숙소 검색(자동완성)을 1번 부른다.
   보내는 것은 숙소 이름뿐. 30일 캐시, 하루 100번, 차단 신호면 24시간 중지. 위장·우회하지 않는다
3. **가격 기록:** 서버 SQLite `lodging_price_reports`. 숙소 키·이름·도시, 숙박 날짜·박 수·인원·객실, 앱·경로, 가격·1박/총액·통화·세금, 선택 칩, 본 시각, 작성자 id.
   작성자 id는 내 기록 삭제·한도에만 쓰고 응답에 넣지 않는다. 30일 뒤 지우고, 탈퇴하면 바로 지운다.
   여행·좌표·예약 번호·자유 글·자동으로 가져온 가격은 저장하지 않는다
4. **가계부와 구분:** 가격 기록은 "앱에서 본 가격 제보"다. 내 지출·예산·정산이 아니고 예약·여행과 연결하지 않는다
5. **구글 호텔 참고 가격 (나중 단계):** 서버 → SerpApi로 숙소 이름·도시·날짜·인원·통화만 보낸다. 저장·공유하지 않고 기록 칸에 미리 채우지 않는다.
   `guardApi`·`trackApi`로 무료 월 250회의 95%에서 멈춘다 (과금 없음)
6. 모든 API는 로그인 필요. 사람별·서버 전체 한도, 캐시, 동시 실행 상한, 차단기, 자동 재시도 없음 (설계 §8)
7. 개인정보 처리방침에 가격 기록(30일, 다른 사용자에게 공개, 작성자 비공개)과 아고다·SerpApi 전송을 적는다

## 검토한 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| 서버가 경로마다 아고다 가격을 읽기 | 앱 안에 가격이 바로 보임 | 경로 23개 = 요청 23번, 집 PC IP 차단·약관 위험 |
| 예약 앱 직접 조회 (트립닷컴·여기어때·NOL) | 국내 앱 가격도 보임 | 약관 위반 소지, 사이트가 바뀌면 고장 — 사용자 결정으로 제외 |
| 공식 제휴 API | 안정적 | 승인 심사가 필요하고 개인 앱은 어려움 |
| 아고다스캐너 사이트로 보내기 | 만들 것이 적음 | 광고·분석이 있는 외부 사이트 — 사용자 결정으로 제외 |
| 기록을 같은 여행 멤버만 보기 | 사생활 걱정이 적음 | 기록이 덜 모임 — 사용자 결정으로 로그인한 모두 |

## 결과 (Consequences)
- 좋아지는 점: 서버 부담과 외부 요청이 거의 없다 (자동 찾기 1번). 쌓인 기록으로 "어느 경로가 싼지"가 보인다
- 감수하는 점: 가격을 보려면 링크를 눌러야 한다. 기록은 사람이 적은 값이라 틀릴 수 있다 ("확인 필요" 표시, 관리자 삭제).
  앱 사용자가 적어서 기록으로 "누가 어디에 가는지" 짐작될 수 있다 (작성자 비공개, 날짜만 표시, 안내 문구로 줄임).
  아고다가 링크 모양이나 자동완성을 바꾸면 고쳐야 한다
