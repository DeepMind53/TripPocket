# 01. 제품 요구사항 (PRD)

- 문서 상태: 초안 v0.3 (2026-10-22) — v0.2: 로그인/홈 서버 동기화, 지도·장소·길찾기 추가 / v0.3: **가계부 제외**, 저장한 장소·공유 보기 추가
- 우선순위 표기: **P0** = MVP 필수 / **P1** = 출시 직후 / **P2** = 나중에 / **?** = 결정 필요

## 1. 비전
> "여행 준비부터 여행 중, 다녀온 후까지 — 일정·예약·짐·돈을 한 화면에서, 인터넷 없이도."

기존 여행 앱들은 (1) 회원가입 강요, (2) 예약/광고 유도, (3) 온라인 의존이 강하다.
이 앱은 **가볍고, 사적이고, 오프라인에서도 확실히 동작하는 개인 여행 수첩**을 목표로 한다.

## 2. 목표 / 비목표
### 목표
- G1. 설치 없이 URL로 접속 → 30초 안에 첫 여행 생성
- G2. 여행 중 비행기 모드에서도 모든 조회/편집 가능
- G3. 일정(시간순) · 장소(지도) · 예약정보 · 준비물을 한 여행 안에서 관리
- G4. 데이터 유실 방지: 쉬운 백업/복원, 기기 간 이동
- G5. 동행자에게 일정 공유 및 공동 편집 (로그인 시)
- G6. 로그인하면 홈 PC 서버에 저장 → 어느 기기에서든 불러오기
- G7. 구글/네이버 지도로 장소 확인, 평점·리뷰로 숙소·음식점·볼거리 고르기, 현재 위치에서 길찾기

### 비목표 (당분간 하지 않음)
- 실시간(초 단위) 공동 편집 — 동기화 주기 반영으로 시작, 실시간은 P2
- 항공/숙소 예약·결제
- 자체 리뷰 작성/커뮤니티
- **가계부(지출 기록·예산·정산·환율)** — 사용자 결정으로 제외 (2026-10-22)
- 소셜 피드, 리뷰, 추천 콘텐츠

## 3. 페르소나
| 페르소나 | 상황 | 핵심 니즈 |
|---|---|---|
| **꼼꼼한 계획러** (30대 직장인) | 연 2~3회 해외여행, 엑셀/노션으로 일정 짬 | 시간 단위 일정, 예약번호 정리, 동선 확인 |
| **동행 리더** (가족여행 총무) | 부모님·아이 동반 | 일정 공유(로그인 없는 가족도 보기), 준비물 체크리스트 |
| **즉흥 여행자** (20대) | 대략적인 리스트만 | 가고 싶은 곳 위시리스트, 지도에서 보기 |

## 4. 핵심 사용 시나리오
1. **계획**: 여행 생성(도시/기간) → 가고 싶은 장소 위시리스트에 담기 → 날짜별로 배치 → 순서 드래그
2. **예약 정리**: 항공권·숙소 정보(예약번호, 체크인 시간, 주소) 입력 → 일정에 자동 표시
3. **준비**: 템플릿 기반 준비물 체크리스트
4. **여행 중**: "오늘" 화면에서 다음 일정·주소·예약번호 즉시 확인, 지도 앱으로 길찾기 연결, 주변 맛집·카페 찾기
5. **공유**: 링크/파일로 동행자에게 일정 전달 (읽기 전용 또는 가져오기)
6. **여행 후**: 다녀온 여행으로 보관, 다음 여행에 복제해서 재사용

## 6. 비기능 요구사항
| 항목 | 기준 |
|---|---|
| 성능 | 첫 로드 JS ≤ 200KB(gzip), 3G에서 LCP < 2.5s, 재방문은 오프라인 즉시 로드 |
| 오프라인 | 최초 1회 방문 후 모든 핵심 기능 오프라인 동작 |
| 지원 환경 | iOS Safari 16.4+, Android Chrome 최신 2버전, 데스크톱 Chrome/Edge/Safari/Firefox |
| 접근성 | WCAG 2.1 AA 지향: 터치 타깃 44px, 명도 대비, 스크린리더 라벨 |
| 개인정보 | 사용자 데이터는 홈 서버 외 전송 0건, 위치 서버 미저장, 수집 최소화, 개인정보처리방침 게시 |
| 보안 | `09-server-auth-security.md` §7 체크리스트 100% 충족 후 외부 공개 |
| 서버 가용성 | 홈 PC 다운 시에도 앱 사용 가능(로컬 모드), 복구 후 자동 동기화 |
| 외부 API 비용 | 월 무료 사용량 이내 목표, 클라우드 결제 알림·일일 상한 설정 |
| 데이터 안전 | 스키마 마이그레이션 자동 테스트, 가져오기 전 자동 백업 스냅샷 |
| 용량 | 여행 50개, 아이템 5,000개, 첨부 200MB 수준에서 원활 |
