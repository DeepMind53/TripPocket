# 25. 여행 모드 (간략 모드) — 설계 제안

- 상태: **제안** (사용자 확인 전 구현하지 않음)
- 날짜: 2026-11-02
- 요청: 일정·예약 준비를 마치면 "여행 모드"로 바꿔, 고치는 기능 없이 **오늘·내일 일정에 집중**하고
  **빠르고 쉽게 찾는** 간략한 화면으로 여행을 돕는다

## 1. 목표와 원칙
| 원칙 | 뜻 |
|---|---|
| 지금 → 다음 | 화면을 열면 3초 안에 "지금 할 일·다음 할 일·어떻게 가는지"가 보인다 |
| 한 번에 하나 | 한 화면에 한 날짜. 오늘과 내일 두 칸만 기본으로 |
| 고치지 않는다 | 추가·편집·삭제·끌어 옮기기·설정 버튼을 숨긴다 (잘못 눌러 바뀌는 일 없음) |
| 한 손·밖에서 | 큰 글씨·큰 버튼·햇빛에서도 보이는 대비, 아래쪽 엄지 영역에 주요 버튼 |
| 인터넷 없어도 | 모든 정보는 기기에서. 인터넷이 필요한 것은 따로 표시하고 실패해도 화면이 멈추지 않는다 |
| 언제든 돌아가기 | 여행 모드는 잠금이 아니다 — [편집 모드로] 한 번이면 지금 화면 그대로 돌아간다 |

## 2. 켜고 끄기
1. **준비 완료 확인 → 제안**: 출발 3일 전부터 여행 화면 위에 "준비가 끝났나요? 여행 모드로 볼까요?" 한 줄.
   필수 항목(여권·전자여행허가)·항공·숙소 예약 상태를 짧게 보여 주고 [여행 모드 시작]
2. **출발일 자동 제안**: 출발 당일 처음 열면 한 번 더 묻는다 (거절하면 그 여행에서는 다시 묻지 않음)
3. **직접 켜기**: 여행 메뉴(⋯) → [여행 모드]
4. **끄기**: 여행 모드 화면 오른쪽 위 [편집] → 일반 화면. 귀국 다음 날 자동으로 꺼지고 "여행 회고" 안내
5. **누구 기준인가**: 기기마다 따로 (동행 화면에는 영향 없음) — 결정 D1

## 3. 화면 구성 (안)
```
┌ 도쿄 3일차 · 11.07 (목)        [편집] ┐   ← 머리: 여행 이름 대신 "몇일차·날짜", 현지 시각
│ ☀ 18°/11° · 오후 비 ☂                 │   ← 날씨 한 줄 (주의가 있을 때만 그림)
├──────────────────────────────────────┤
│ 지금  센소지 (09:00–10:30)             │   ← 진행 중 일정: 크게, 남은 시간
│       남은 40분                         │
│ 다음  아사쿠사 멘치 11:00  도보 8분 [길찾기]│   ← 다음 일정 + 이동 시간 + 한 번에 길찾기
├──────────────────────────────────────┤
│ 오늘 남은 일정 (3)                      │   ← 시각·이름·종류 아이콘만, 메모는 접기
│  13:00 도쿄타워   15:30 긴자   19:00 숙소 │
├──────────────────────────────────────┤
│ [오늘] [내일]                           │   ← 두 칸 전환 (전체 일정은 "다른 날 보기")
├──────────────────────────────────────┤
│ 🏨 숙소 가기  🚕 택시 카드  🎫 예약번호     │   ← 엄지 영역 6칸 (편집 가능, 빠른 메뉴와 공유)
│ 📍 위치 저장  🆘 긴급     💱 환율         │
└──────────────────────────────────────┘
```
- **지금·다음 카드**: 이미 있는 "다음 일정 바"(이동 시간 검색·출발 시각)를 크게 키운 모양. 시각이 없는 일정은 "오늘 할 일" 목록으로
- **이동 카드**: 출국 비행기 → 렌터카 → 귀국 비행기 (빠른 메뉴 `travelLeg` 규칙 그대로), 그날 숙소 체크인·체크아웃
- **내일 미리보기**: 첫 일정 시각·출발 장소·준비물(날씨 주의 그림) 한 줄 — "내일 아침 7시 출발, 우산"
- **다른 날 보기**: 날짜 목록만 (지난 날은 방문·미방문 결과만)

## 4. 숨기는 것 (간략하게)
| 일반 화면 | 여행 모드 |
|---|---|
| 일정 추가(+)·편집 모드·끌어 옮기기·하루 메뉴 | 숨김 |
| 일차 칩 줄 전체 | [오늘][내일] 두 칸 + "다른 날 보기" |
| 지도 칸 | 접힘 → [지도] 버튼 (인터넷 필요 표시) |
| 일정 상세의 입력 칸 | 보기 전용 상세 (주소·전화·예약번호·길찾기·메모) |
| 예약 탭 | "필요할 때 꺼내 보기" 목록: 예약번호·바우처·문서·공항 정보만 |
| 준비물 | 여행 중엔 "현지에서 살 것"·체크 안 된 것만 |
| 설정·실험실·AI 추천 큰 카드 | 빠른 메뉴 안으로 |

## 5. 빠르고 쉽게 찾기 — 아이디어
1. **검색 한 칸**: 머리 아래 "찾기" — 일정·예약·저장 장소·예약번호를 한 번에 (지금 있는 "여행 안 검색" 재사용)
2. **최근 본 것**: 마지막에 연 예약·바우처 3개를 위에 고정 (공항·호텔 프런트에서 다시 꺼내기 쉽게)
3. **상황 카드 자동 순서**: 시간대로 카드 순서를 바꾼다 — 아침: 날씨·첫 일정 / 공항 가는 날: 항공·체크인 카운터 / 밤: 숙소 가기·내일 미리보기
4. **한 번 탭 길찾기**: 모든 장소에 [길찾기] — 설정한 지도 앱으로 바로 (국내 네이버·카카오, 해외 Google)
5. **보여 주기 모드**: 숙소 주소·택시 카드·건강 카드·바우처를 화면 가득 (현지인에게 보여 주기)
6. **꾹 눌러 복사**: 예약번호·주소·전화는 길게 누르면 복사
7. **오프라인 배지**: 인터넷이 필요한 버튼(지도·이동 시간·AI)에 작은 구름 표시, 꺼져 있으면 대신 할 수 있는 것 안내

## 6. 여행 중 편의 (선택 기능 — 결정 D3)
- **출발 시각 알림**: 다음 일정 이동 시간을 넣어 "10분 뒤 출발" 알림 (푸시, 켤 때만)
- **화면 켜짐 유지**: 길찾기·보여 주기 화면에서만 (배터리 안내)
- **햇빛 모드**: 대비를 높이고 글씨를 한 단계 크게
- **하루 마무리**: 밤 9시 이후 "오늘 방문·미방문 표시" 한 번에 (지금 있는 방문 버튼 재사용)
- **동행 위치**: 하지 않음 — 위치를 서버에 저장하지 않는 원칙(CLAUDE.md)

## 7. 데이터·구현 (안)
- 새 서버 데이터 없음. 기기 설정 `travelMode: { tripId, on, declinedAt }` (기기마다) — 결정 D1
- 라우트: `/trips/:tripId/go` (여행 모드 화면). 일반 화면과 같은 데이터(Dexie)·같은 부품(다음 일정 바·FlightTicket·ShowCard)을 쓴다
- 지연 로딩으로 첫 화면 크기 영향 없음
- 오프라인: 이미 기기 DB만 읽음. 이동 시간·지도·공항 정보는 실패해도 마지막 값 + 확인 시각 표시

## 8. 단계 (각 단계 끝에 사용자 확인)
1. **1단계 — 기본 화면**: 켜고 끄기, 오늘·내일, 지금·다음 카드, 남은 일정, 엄지 버튼 6칸, 편집 숨김
2. **2단계 — 찾기**: 검색 한 칸, 최근 본 것, 보기 전용 상세·예약 목록
3. **3단계 — 상황 카드**: 시간대별 순서, 내일 미리보기, 공항 가는 날 카드
4. **4단계 — 선택 기능**: 출발 알림, 햇빛 모드, 하루 마무리 (D3에서 고른 것만)

## 9. 결정이 필요한 것 (하나씩 여쭤볼게요)
| 번호 | 질문 | 추천 |
|---|---|---|
| D1 | 여행 모드를 기기마다 따로 할까, 계정(모든 기기)으로 할까 | 기기마다 |
| D2 | 출발 당일 자동으로 켤까, 묻기만 할까 | 묻기만 (한 번) |
| D3 | 6절 선택 기능 중 무엇을 넣을까 | 출발 알림·햇빛 모드 |
| D4 | 엄지 버튼 6칸을 빠른 메뉴 바로가기와 같은 목록으로 할까 | 같은 목록(편집 한 곳) |
| D5 | 여행 모드에서 일정 체크(방문 표시)는 허용할까 | 허용 (편집은 아님) |
| D6 | 귀국 다음 날 자동으로 끄고 여행 회고로 보낼까 | 예 |

## 10. 확인 방법
- 360px·320px·글자 130%에서 "지금·다음"이 첫 화면 안에 보이는지 (E2E text-fit·layout)
- 비행기 모드에서 여행 모드를 열고 오늘·내일·예약번호·바우처·건강 카드가 모두 보이는지 (offline E2E)
- 편집 버튼이 어디에도 없는지, [편집]으로 돌아가면 같은 날짜가 열리는지
