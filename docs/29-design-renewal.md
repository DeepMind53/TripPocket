## 2. 디자인 방향 (unslop 5줄 — `11` §13을 넓힌 것)
- **제품**: 휴대폰 하나로 여행 일정·예약·준비물을 오프라인에서도 바로 꺼내 보는 앱
- **성격**: 차분하고 정확한 여행 비서 — 들뜬 장식 대신 정확한 시간·숫자, 길에서 한 손으로
- **세계**: 지하철 노선도 · 탑승권 · 여권 도장 · 공항 안내판(고정폭 숫자)
- **모먼트(화면마다 하나만 밝게)**: 홈·여행 모드의 다음 역 카드 / 일정의 노선 / 예약의 탑승권 / 기록의 여권 도장 / 환율의 큰 숫자
- **시그니처**: 일차 색 **노선 선 + 역 점** (로고의 점선 비행 경로와 같은 생각). 노선 선은 일정·지도·홈·여행 모드·공유 보기에만 쓰고 다른 곳에는 쓰지 않는다

### 2.1 화면 문법
| 여행에서 | 화면 문법 | 모양 | 쓰는 곳 |
|---|---|---|---|
| 하루 일정 | 노선 | 세로 선(일차 색) | 일정, 홈 오늘, 여행 모드, 공유 보기 |
| 장소 | 역 | 선 위 원(번호) | 일정 줄, 지도 핀 |
| 메모 | 정류장 아님 | 둥근 네모(번호 없음) | 일정 메모 줄 |
| 이동 | 환승 표시 | 역 사이 작은 알약 | 일정, 여행 모드 |
| 지금 | 진행 | 지난 구간 흐림, 다음 역 채움 + 고리 | 일정(여행 중), 홈, 여행 모드 |
| 이동 예약 | 탑승권 | 절취선 + 큰 코드 + 3칸 | 예약, 홈 출발 전, 일정 안 항공·기차 줄 |
| 그 밖 예약 | 안내표 | 2~3칸 정보표 | 예약(숙소·투어·렌터카·식당·기타) |
| 준비 | 출발 게이트 | 진행 막대 + 남은 필수 수 | 준비, 홈 준비 카드 |
| 지난 여행 | 여권 도장 | 원·네모 도장 | 기록 (Q6) |

### 2.2 원칙
1. **한 화면 한 모먼트**: 위 모먼트 하나만 색·크기를 쓰고 나머지 틀(헤더·탭·버튼·목록)은 회색 단계 + 파랑 하나
2. **색은 뜻이 있을 때만**: 파랑 = 앱의 주된 행동·선택, 일차 색 = 그날 노선, 상태색 = 성공·주의·위험. 종류 색(관광·맛집…)은 아이콘 칸 배경 점으로만
3. **숫자가 주인공**: 시간·코드·금액·박 수는 고정폭(`tabular-nums`, 코드는 `font-mono`), 줄 오른쪽 끝 정렬
4. **지금 중요한 것이 위**: 여행 중이면 "다음 역"이 그 화면 첫 정보 (§15 Q1·Q2)
5. **누르는 것은 누르는 것처럼**: 버튼은 채움(주) / 옅은 파랑(보조) / 글자(셋째) 세 단계만, 목록 줄 전체가 눌리는 곳은 오른쪽 `›`
6. **unslop 체크리스트 그대로** (`11` §13): 굵기 400·500·600, 최소 11px, 토큰 색만, lucide 선 아이콘 1.75, 느낌표 금지, 한 줄 = 한 문장, `transition-all` 금지, 깜빡임 금지

| 숫자 | `tabular-nums` (지금 `.tabular`) | 모든 시간·금액·박 수·개수 |
| 새 크기 `code-xl` | 28/32, 500 | 탑승권 출발·도착 코드 |

## 4. 공통 부품 (`apps/web/src/shared/ui/`)
모두 기존 토큰만 쓰고 새 의존성 없음. 각 부품은 `/dev/ui`에 견본(라이트·다크·좁은 화면·글자 130%)을 둔다.

### 4.1 `RouteStop` · `RouteLine` — 노선과 역
```
[점]  제목(1줄, 넘치면 …)                 시간
 │    보조줄: 종류 · 주소/메모 (1줄)
 │
[점]  …
```
- 구조: `<ol>` 안 `<li>`마다 왼쪽 24px 칸(점 + 아래로 이어지는 선) · 가운데 `minmax(0,1fr)` · 오른쪽 시간(고정폭, 오른쪽 정렬)
- 상태: 기본 / 지난(점·선 흐림, 제목 `text-muted`, 굵기 500) / 다음(점 채움 + 고리, 보조줄에 "다음 · 38분 뒤" 파랑) / 방문함(점 안 체크) / 미방문(점 안 가로줄) / 메모(둥근 네모, 번호 없음) / 선택됨(지도 핀을 눌렀을 때: 줄 배경 `bg-day-N-weak` 1초 뒤 서서히 사라짐 — 지금 강조와 같은 동작)
- 마지막 역 아래로는 선이 없다. 시간 없는 역은 오른쪽에 `—`
- 크기: 기본 줄 최소 56px(누르는 영역), 촘촘히 보기 44px
- 접근성: 점 색만으로 구분하지 않음 — 점 안 번호 + `aria-label="2일차 3번째, 센소지, 14시"`. 지금 목록의 접근 이름(테스트가 쓰는 이름)은 그대로 둔다
- 끌어 옮기기(편집 모드)·스와이프 동작은 지금 `ItemRow`의 것을 그대로 감싼다

### 4.2 `TransferChip` — 역 사이 이동
- 모양: 노선 선 오른쪽에 붙는 알약 `[길 아이콘] 850m · 길찾기` (높이 22, `bg-subtle`, 글자 11~12, 숫자 `tabular-nums`)
- 값: **지금 있는 정보만** — 설정 "다음 장소까지 거리"(`legDistance`)를 켰을 때 직선거리, 예약된 이동(기차·버스·항공)은 그 예약 시각. **시간 어림은 넣지 않는다 (Q8)** — 이동 시간은 지금처럼 위쪽 다음 일정 줄(`NextStopBar`, 서버 이동 시간)과 길찾기 앱에서
- 누르면 지금처럼 길찾기 시트 (`LegLine`의 동작 그대로)
- 꺼져 있으면(설정 끔) 칩 없이 선만 이어진다

### 4.3 `DayLineTabs` — 일차 고르기
- 가로 스크롤 알약: `전체` · `1일 11.24` · `2일 11.25` … · `가고 싶은 곳`
- 선택 = 노선 색 채움 + 흰 글자, 나머지 = 노선 색 1.5px 테두리 + 노선 진한 글자. `전체`·`가고 싶은 곳`은 회색
- 오늘 일차는 알약 위 작은 점 (지금과 같음). 선택 알약은 화면 안으로 자동 스크롤
- 높이 34(칩 규칙), 누르는 영역 44

### 4.4 `NextStopCard` — 다음 역 (홈·여행 모드)
```
다음 역 · 지하철 24분                (작게, 흰색 85%)
센소지                                (title-1)
38분  뒤 14:00                        (count-xl 고정폭 + 보조)
[━━━━━━━━━━━━──────]                  (진행 막대)
하마리큐 정원                  센소지  (지난 역 → 다음 역)
[ 길찾기 ]  [ 일정 보기 ]
```
- 배경: 파랑 채움 `--color-primary`, 글자 흰색 (Q3). 보조 버튼 [일정 보기]는 흰 글자 + 흰 20% 배경, [길찾기]는 흰 바탕 + 파란 글자
- 진행 막대: (지금 − 지난 역 시각) ÷ (다음 역 시각 − 지난 역 시각). 지난 역이 없으면 막대 없음. 1분마다 갱신(지금 `useMinuteTick`)
- 남은 시간 문구는 지금 키(`home.inMinutes`·`inHours`·`now`) 그대로
- 다음 역이 없을 때: 지금처럼 "오늘 일정을 다 했어요" + 내일 첫 일정 링크 (회색 칸)

### 4.5 `TicketCard` — 탑승권·안내표
| 종류 | 위 칸 | 절취선 | 아래 3칸 |
|---|---|---|---|
| 항공 | 항공사·편명·날짜 / `ICN ┈✈┈ NRT` 코드 28px + 시각·터미널 | 있음 | 예약번호(파랑 고정폭, 눌러 복사) · 좌석 · 수하물 |
| 기차·버스 | 노선·열차번호 / 출발역 ┈ 도착역(코드 대신 역 이름 20px) + 시각 | 있음 | 예약번호 · 호차·좌석 · 승강장(있으면) |

| 렌터카 | 업체·차종 / 인수 지점 → 반납 지점 | 없음 | 인수 시각 · 반납 시각 · 예약번호 |

- 회원번호·등급(`member`)은 아래 칸 밑 한 줄 (지금처럼 고정폭)
- 카드 아래 붙는 부가 정보(공항 정보·지연·수하물·문서·안내)는 **접히는 줄**로 (§7.9)
- 탑승권 모양은 항공·기차·버스만 (Q11)

### 4.6 `GateProgress` — 출발 게이트
- `출발 게이트   12/18` + 진행 막대(성공색) + 아래 한 줄 "필수 2개 남았어요"(주의색 글자) / 다 되면 "모두 준비됐어요"(성공색)
- 준비물·할 일 탭마다 각자 숫자 (지금 `checklist.progress`·`progressTodo`)

### 4.7 `Stamp` — 여권 도장 (Q6)
- SVG 하나: 원 또는 둥근 네모(여행마다 번갈아), 바깥 선 2.5 + 안쪽 점선 1, 도시 영문 대문자 고정폭 11px + 연월, 회전 −10°~+10°(여행 id로 정해 늘 같게)
- 색: 그 여행 1일차 노선 진한 글자색, 85% 불투명. 누르면 그 여행
- 대문자 도시명은 도장 안 그림 글자라 unslop "대문자 라벨 금지"의 예외로 적는다

## 7. 화면별 설계
각 화면: **지금 들어 있는 것**(빠짐없이) → **새 배치**(위에서 아래) → **편하게 바꾸는 점** → **상태**.

### 7.1 홈 (시안 4.1)
**지금 들어 있는 것**
- 헤더: 여행 모드 버튼(실험실, 왼쪽) · 로고(가운데) · 도움말(오른쪽)
- 여행 없음: 빈 화면 + [새 여행 만들기] + [샘플 여행으로 둘러보기]
- 백업 권유 띠(`BackupReminder`)
- 대표 여행 카드(`UpcomingTrip`: 배지·이모지·제목·기간·일정 수·예약 수·준비물 진행) — 여행 중엔 민트
- 준비 카드(`PrepCards`, 출발 30일 전부터, 여행 중엔 접힘): 준비물·예약·날씨·환율·AI·출국 준비(essentials)·주의 점
- 내 여행 섹션: 제목 + [새 여행] + 여행 목록(`TripList active`)
- 여행 중 묶음(`OngoingTrip`): 특보 띠(`TripAlertBanner`) · 실험실 한 줄(`HomeLabs`) · 다음 일정 카드(길찾기·일정 보기) 또는 "다 했어요 + 내일 첫 일정" · 오늘 일정 목록(시간·제목·방문 표시) · 오늘 숙소(박 차·길찾기·예약번호 복사) · 길찾기 시트

**새 배치 — 여행 중**
1. 헤더 (그대로)
2. 백업 권유 띠 (있을 때만, 그대로)
3. **대표 여행 줄**: 지금 큰 민트 카드 → **한 줄 높이 띠**(이모지 · 제목 · "2일차" 배지 · 노선 막대) — Q2
4. 특보 띠 · 실험실 한 줄 (그대로, 최대 2개 규칙)
5. **`NextStopCard`** (모먼트)
6. **오늘 노선**: 지금 시간·제목 목록 → `RouteLine` 축소판(남은 역 위주, 지난 역은 접혀 "지난 2곳" 한 줄, 누르면 펼침). 지난 역의 [방문][미방문]은 펼쳤을 때 그대로
7. **오늘 숙소**: 안내표 모양(숙소 이름 · 박 차 `2/3` · [길찾기] [예약번호 복사])
8. 준비 카드(접힘, 그대로)
9. 내 여행 목록(다가오는 여행만, 노선 막대 카드)

**새 배치 — 출발 전 (다가오는 여행)**
1. 헤더 · 백업 띠
2. **다음 이동이 항공·기차면 `TicketCard`** (모먼트) + 위에 "도쿄 3박 4일 · D-15" 한 줄 / 이동 예약이 없으면 지금 대표 여행 카드(표지 색) 그대로
3. 준비 카드: 첫 칸 `GateProgress`(준비물) → 예약·날씨·환율·출국 준비·AI (지금 순서 그대로)
4. 내 여행 목록

**여행 없음**: 그대로 (빈 화면 아이콘만 `luggage` 유지)

**편하게 바꾸는 점**
- 여행 중 가장 많이 보는 다음 일정이 위로 (지금은 큰 여행 카드가 첫 화면 1/3 차지)
- 오늘 숙소 예약번호를 다음 역 카드 바로 아래 두 번째 자리 → 체크인 때 한 번에
- 지난 일정 접기로 남은 일정이 첫 화면에

- 기록 가 본 나라(`CountryGrid`): 칸 → 여권 도장 (도장 안 나라 이름·"N번", 아래 국기 — 같은 정보, 누르는 동작은 원래 없어서 더하지 않음)
  - §7.21의 "도시·연월, 누르면 그 여행"은 지금 기능에 없는 정보·동작이라 넣지 않았다 (필요하면 따로 묻기)
- 공개 보기(`/s/:id`): 일차 알약(노선 진한 색) + 일정은 노선(`RouteLine`·`RouteStop`), 예약 줄은 그대로
- 인쇄용 일정표: 그대로 (흑백 인쇄라 노선 색이 의미 없음)

### 13.6 6단계 결과 (2026-11-10) — 새 문구·새 동작 없음
- 설정 "일정" 기능 미리보기(`FeaturePreview`): 일차 알약·번호를 노선 모양(진한 노선 색 알약, 흰 바탕 역 점, 진행 중은 채움 + 테두리)으로, 왼쪽 강조 막대·하드코딩 색 제거
- 편집 모드(`EditModeList`) 번호: 색 채움 + 흰 글자 → 노선 역 점 (8색 모두 대비)
- 다크 모드 점검: 일정·노선 부품·기록 도장 스크린샷 확인 (대비 테스트 `contrast.test.ts`)
- **살펴보고 그대로 둔 것** (이미 기준에 맞거나 해당 기능이 없음)
  - 장소 찾기: [담기]는 여행만 고르고 날짜는 고르지 않음 → §7.7의 일차 알약 고르기는 지금 기능에 없어 넣지 않음
  - 저장·빠른 메뉴·회화·AI·날씨·마이: 1·2차 unslop 모양 유지
  - 환율: 이미 큰 고정폭 숫자 + 숫자 자판
  - 숙소 최저가: 구글 참고 가격은 이미 싼 순, 최저 줄 파랑
- 앱 소개 넘기기(`IntroCarousel`)의 그림은 예전 일정 모양 — 소개 그림을 새로 그리는 일은 따로 (문구 없음, 다음 다듬기 때)
