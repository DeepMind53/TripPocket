# 24. 여행지 기상·재난 특보 (설계)

> 2026-10-26 사용자 요청: "태풍·지진·호우주의보 등 여행 가는 나라의 날씨 특이사항을 확인할 방법이 있는지, 있으면 설계 문서".
> **이 문서는 설계만** — 아직 만들지 않았다. 구현은 아래 §6 결정을 받은 뒤.
> 출처·응답은 2026-10-27에 실제로 불러 확인했다 (맨 아래).

## 0. 결론 한 줄

무료로 가능하다. **전 세계는 GDACS(태풍·지진·홍수·화산) + USGS(지진)**, **일본은 기상청 JSON(경보·주의보·지진)**, 그리고 **외교부 여행경보 API**(안전 등급)를 합치면 여행 중·출발 전 주요 특이사항을 대부분 덮는다.
모두 키가 없거나 무료 키이고, 과금되지 않는다.

## 1. 쓸 수 있는 출처

| 출처 | 내용 | 범위 | 키·비용 | 확인 |
|---|---|---|---|---|
| GDACS (UN·EU 공동) | 태풍(TC)·지진(EQ)·홍수(FL)·화산(VO)·산불(WF) 경보 등급(초록·주황·빨강), 피해 나라 | 전 세계 | 키 없음, 무료. 출처 표기 "Global Disaster Alert and Coordination System, GDACS" | `gdacsapi/api/events/geteventlist/SEARCH` 응답 확인 (2026-10 주황·빨강 8건) |
| USGS 지진 피드 | 최근 1주 주요 지진(규모·위치·시각) GeoJSON | 전 세계 | 키 없음, 무료 (미국 정부 공공 자료) | `summary/significant_week.geojson` 200 응답 |
| 일본 기상청(JMA) JSON | 지역별 기상 경보·주의보(호우·폭풍·대설 등), 지진 목록 | 일본 | 키 없음. 공공데이터 이용규약 1.0 — 출처 "출처: 기상청 홈페이지(URL)", 가공했으면 가공했다고 표시 | `bosai/warning/data/warning/130000.json`(도쿄), `bosai/quake/data/list.json` 200 응답 |
| 외교부 여행경보 API (공공데이터포털) | 나라·지역별 여행경보 단계, 특별여행주의보 | 전 세계 | 무료 키 (공공데이터포털 활용 신청 — 사용자 작업), 개발 계정 하루 1만 건 | 상세 페이지 확인 (15076237, 15076244) |
| (참고) 대만 CWA·태국 TMD·미국 NWS 등 | 나라별 기상 경보 | 각 나라 | 대부분 무료 (일부 키) | 미확인 — 2단계 후보 |

넣지 않는 것: 유료 기상 API, 사용자 위치 기반 알림(위치는 서버에 저장하지 않는 규칙).

## 2. 보여 줄 곳 (제안)

1. **날씨 정보 화면**(홈 "날씨 정보" 카드) 맨 위에 "여행지 특이사항" 칸
   - 없으면 "특이사항 없어요" 한 줄
   - 있으면 종류 아이콘 + 한 줄 요약 + 공식 출처 링크 (예: "🌀 태풍 ○○ — 오키나와 영향 · 주황 경보")
2. **여행 중·출발 7일 전부터** 홈 카드에 빨간·주황 점 (빨강 = GDACS 빨강·일본 경보, 주황 = GDACS 주황·일본 주의보)
3. (선택) 알림: 빨강 등급이 새로 생기면 푸시 1번 — 기존 알림 기능(docs/20) 재사용

## 3. 판단 규칙

- 여행 나라(목적지 countryCode)와 **기간(출발 7일 전 ~ 귀국일)** 이 겹치는 사건만
- GDACS: 피해 나라 목록(`affectedcountries.iso2`)에 여행 나라가 있고 등급 주황 이상
- USGS: 여행지 좌표 300km 안, 규모 5.5 이상, 최근 72시간
- JMA: 여행 도시가 속한 지역 코드(`area.json`)의 경보·주의보 — 일본 여행만
- 외교부: 여행경보 단계가 있으면 늘 표시 (특별여행주의보는 강조)

## 4. 구조 (구현할 때)

- 서버 `services/alerts.ts`: 출처별로 받아 공통 형식 `{ kind, level, title, area, from, until, source, url }`으로
- 서버가 **10분마다 한 번** 받아 메모리에 둔다 (사용자 수와 관계없이 호출 수 일정 — 무료·예의)
- `GET /api/alerts?countries=JP,TW&from=…&to=…` (로그인 필요). 좌표는 보내지 않고 나라·기간만
- `APIS`에 `gdacs`·`usgs`·`jma`·`mofa_alert` 등록 (무료, 하루 상한만 — `guardApi`·`trackApi`)
- 웹: 날씨 정보 화면에서 불러오고 기기에 1시간 보관(오프라인이면 마지막 결과 + "확인 시각")

## 5. 주의

- 경보는 **참고용** — "공식 발표를 꼭 확인하세요" + 원문 링크를 항상 함께
- 일본 기상업무법상 다른 곳이 경보를 "발표"하면 안 된다 → 기상청 발표를 출처와 함께 **그대로 옮겨 보여 주기만**, 자체 판단 문구 금지
- 번역: 원문(영어·일본어) 제목은 짧은 한국어 종류명(태풍·지진·호우 등)으로만 바꾸고 나머지는 원문 링크

## 6. 결정이 필요한 것 (사용자)

| # | 질문 | 기본안 |
|---|---|---|
| A1 | 1단계 출처: GDACS + USGS + 일본 기상청 | 넣는다 |
| A2 | 외교부 여행경보 API — 공공데이터포털 키 신청(사용자) | 넣는다 |
| A3 | 빨강 등급 새로 생기면 푸시 알림 | 넣는다 (하루 1번까지) |
| A4 | 대만·태국·미국 등 나라별 기상청은 2단계로 | 2단계 |
