# 25. 항공편 기종·좌석 안내 (설계)

> 2026-10-28 사용자 요청: "항공권 입력 시 기종도 알아내고, 그 기종의 기내 좌석 번호도 알 수 있을까?
> 좌석별 특이사항(비상구석·좌석 간격이 넓은 좌석)이 있으면 안내. 무료 API가 있으면 받아오고, 없으면 알 수 있는 방법을 찾자.
> 구현 전 상세 설계 문서 먼저."
> 상태: **설계 초안 — §8 결정 후 구현**. 출처·응답은 2026-10-28에 실제로 불러 확인했다 (§9).

## 0. 결론 한 줄

- **기종은 무료로 알 수 있다.** 지금 쓰는 AviationStack 무료 응답에 기종(`aircraft.iata/icao`, 예: `B78X` = 보잉 787-10)과 기체 등록번호(예: `HL8572`)가 이미 들어 있다.
  - 추가 호출이 없고, 비용도 0원이다.
- **좌석별 특이사항(비상구·넓은 좌석)을 주는 무료 API는 없다.**
  - Amadeus Self-Service(좌석 배치도 무료 API)는 2026-07-17 종료됐다.
  - Sabre·Travelport·Aerocrs는 기업 계약이 필요하다.
  - AirLabs는 좌석 배치 API를 제공하지 않는다.
- 그래서 세 가지를 합친다.
  1. **기종별 기본 배열**: 좌석 글자로 창가·통로·가운데를 판단한다. 직접 만든 표라 무료이고 정확하다.
  2. **항공사·기종별 좌석 메모 데이터**: 비상구 줄, 다리 공간 넓은 줄, 창문 없는 자리 등. 항공사 공식 좌석 배치도를 보고 직접 만든다. 출처와 확인일을 함께 적고 매달 확인한다.
  3. **데이터가 없을 때**: 항공사 공식 좌석 배치도와 무료 좌석 배치도 사이트(SeatMaps·aeroLOPA)로 가는 링크를 연다.

## 1. 쓸 수 있는 출처 (2026-10-28 확인)

| 출처 | 주는 것 | 비용·조건 | 판단 |
|---|---|---|---|
| **AviationStack 무료** (이미 사용 중, 편명 불러오기) | 최근 운항의 `aircraft.iata/icao`(기종 코드)·`registration`(등록번호) | 월 100회 무료, 지금 호출에 이미 포함 → 추가 0회 | ✅ **기종에 사용**. 코드셰어 줄은 비어 있어 값 있는 줄을 고른다 (§9) |
| AirLabs 무료 | 편명 조회 `aircraft_icao`(무료 플랜 표시) | 무료 플랜 있음 (한도 미확인) | 대안. 지금은 AviationStack으로 충분 |
| AeroDataBox (RapidAPI Basic) | 편명·날짜로 운항 정보 (기종 포함 여부 미확인) | 월 400 단위 무료, RapidAPI 가입 필요 | 보류 — 미래 날짜 기종이 필요해지면 검토 |
| Amadeus SeatMap Display | 좌석별 비상구·다리 공간·유료 여부 | **2026-07-17 셀프서비스 종료**, 기업 계약만 | ❌ |
| Sabre Get Seats / Travelport / Aerocrs | 좌석별 특성 | 기업·여행사 계약 | ❌ (무료 아님) |
| AirLabs 좌석 배치 | — | "좌석 배치 API 없음"(공식 페이지) | ❌ |
| SeatMaps.com | 항공사·기종별 좌석 배치도 웹페이지 (`/airlines/ke-korean-air/boeing-787-10/`) | 보기는 무료, API 없음 | ✅ **링크만** (긁어 오지 않음) |
| aeroLOPA | 정밀 좌석 배치도 웹 (`/oz` 등 항공사 페이지) | 보기는 무료, API는 파트너 전용 | ✅ **링크만** |
| 항공사 공식 좌석 배치도 | 가장 정확 | 무료 (웹·PDF) | ✅ **좌석 메모 데이터의 출처** + 링크 |

넣지 않는 것:
- 유료 좌석 API
- 다른 사이트 내용 긁어 오기(스크래핑) — 이용 약관 위험
- AI로 좌석 정보 추측하기 — 틀리면 위험하다 (CLAUDE.md: AI는 근거 있는 것만)

## 2. 할 수 있는 것과 없는 것

| 질문 | 답 |
|---|---|
| 편명으로 기종을 알 수 있나 | ✅ 최근 운항 기준. 실제 탈 비행기는 바뀔 수 있어 "최근 운항 기준"이라고 표시한다 (편명 불러오기와 같음) |
| 기종의 좌석 번호 범위·배열(3-3, 3-4-3 등) | ✅ 기종별 기본 표. 같은 기종이라도 항공사마다 배열이 다를 수 있어, 항공사 데이터가 있으면 그것을 먼저 쓴다 |
| 내 좌석이 창가·통로·가운데인지 | ✅ 배열 표로 판단한다 (예: 787 이코노미 3-3-3 → A·L 창가, C·D·H·J 통로) |
| 비상구 줄·다리 공간 넓은 줄·벽 앞 좌석·창문 없는 자리 | △ **항공사·기종 데이터가 있을 때만**. 없으면 "이 항공사 정보 없음 + 공식 배치도 보기" |
| 지금 비어 있는 좌석·유료 좌석 가격 | ❌ 예약 시스템(유료 API)에서만 알 수 있다. 항공사 앱이나 웹으로 안내 |

## 3. 화면 (제안)

### 3.1 예약 입력 (항공)
- [불러오기]를 누르면 시간·공항·터미널과 함께 **기종**도 채운다.
  - 예: "기종 B78X · 보잉 787-10 (최근 운항 기준)"
- 기종 칸은 [+ 더 입력하기] 안에 있고 직접 고칠 수 있다. 자주 쓰는 기종 목록에서 고르거나 코드를 직접 입력한다.
- 좌석 칸에 "34A"를 넣으면 바로 아래에 한 줄이 보인다.
  - 예: "창가 · 비상구 줄 · 다리 공간 넓음"
  - 데이터가 없으면 "창가"만 보인다.

### 3.2 예약 카드 · 일정 탑승권
- 편명 옆에 기종을 작게 보여 준다 (예: "KE703 · B787-10").
- 좌석 줄에 특이사항 아이콘을 보여 준다.
  - 예: "좌석 34A · 🚪 비상구 · 🦵 넓음"
  - 날씨 주의와 같은 간단한 이모지 방식이다.

### 3.3 [좌석 안내] 시트 (탑승권 카드에서 열기)
- **기본 배열 그림**: 줄 번호 × 좌석 글자를 단순한 칸으로 그린다. 라이브러리 없이 CSS 격자로 만들고, 360px에서 가로로 밀어 본다.
  - 칸 표시: 🚪 비상구 줄, 🦵 다리 공간 넓음, ▣ 벽 앞(벌크헤드), 🚫🪟 창문 없음, 내 좌석 강조
  - 칸을 누르면 그 자리 설명이 나온다. 예: "28A · 비상구 줄 · 다리 공간 넓음 · 팔걸이 고정형(테이블은 팔걸이 안)"
- **추천 줄 요약**: "다리 공간 넓은 줄: 28, 45 (비상구)", "앞쪽 줄: 29~31"
- **비상구석 안내**(공통 규칙)
  - 만 15세 이상
  - 비상시 승무원을 도울 수 있어야 하고, 한국어나 영어로 의사소통이 가능해야 한다
  - 유아·반려동물 동반은 불가
  - 짐은 머리 위 선반에 둔다
  - 항공사마다 유료일 수 있다
- **출처·확인일** 표시 + 링크: [항공사 공식 좌석 배치도] [SeatMaps에서 보기] [aeroLOPA에서 보기]
- 데이터가 없는 항공사·기종: 기본 배열(창가·통로)만 보여 주고 "이 항공사 좌석 특이사항은 아직 없어요" + 링크 3개

## 4. 데이터

### 4.1 예약에 저장 (packages/shared, 선택 칸 — 하위 호환)
```ts
details.aircraft?: string      // ICAO/IATA 기종 코드 "B78X" (최대 8자)
details.registration?: string  // 기체 등록번호 "HL8572" — 같은 기종 안의 좌석 배열 구분용 (최대 10자)
```
- 저장하지 않는 것: 좌석 배치 내용(앱에 들어 있는 정적 데이터), 가격
- 보기 전용 공유 링크에서 `registration`은 뺀다. 개인정보는 아니지만 불필요하다.

### 4.2 기종 기본 표 (웹 `domain/aircraft.ts`, 순수 함수 + 테스트)
```ts
AIRCRAFT: { code: 'B78X', name: '보잉 787-10', family: 'B787',
            economy: 'ABC-DEF-GHJ' /* 통로 = '-' */ }
seatPosition('B78X', '34A') → 'window' | 'aisle' | 'middle' | null
```
- 대상: 한국 출발 노선에서 많이 쓰는 약 25종
  - A220-300, A320/321(neo)
  - A330-200/300, A350-900/1000, A380
  - 737-800/8/MAX, 747-8, 767, 777-200/300ER, 787-8/9/10
  - E190 등

### 4.3 항공사·기종 좌석 메모 (웹 정적 JSON, 좌석 안내 시트를 열 때만 불러옴 → 첫 화면 크기 영향 없음)
```jsonc
// src/data/seatmaps/KE.json
{
  "airline": "KE",
  "configs": [{
    "aircraft": "B78X",
    "registrations": ["HL8515", "HL8572"],   // 없으면 그 기종 전체
    "cabins": [
      { "class": "business", "rows": [7, 12], "layout": "A-DH-L" },
      { "class": "economy",  "rows": [28, 60], "layout": "ABC-DEH-JKL" }
    ],
    "exitRows": [28, 45],
    "extraLegroom": [28, 45],
    "bulkhead": [28],
    "noWindow": ["29A"],
    "notes": { "28": "팔걸이 고정형 · 테이블은 팔걸이 안" },
    "source": "https://www.koreanair.com/…(공식 좌석 배치도)",
    "checked": "2026-10-28"
  }]
}
```
- 1차 범위(제안): 대한항공·아시아나 + 국내 LCC 6곳
  - LCC: 제주항공·진에어·티웨이·에어부산·에어서울·이스타
  - LCC는 기종이 2~3개라 양이 적다. 합계 약 30개 배열
- 2차: 일본항공·ANA·중화항공·에바·캐세이·베트남항공·비엣젯·타이·싱가포르 등 한국 노선에 많은 외항사
- 데이터 만들기: 공식 좌석 배치도를 보고 직접 옮긴다(사람 확인 필수). 자동 수집은 하지 않는다.
- 갱신: 관리자 "월간 갱신 요청문"(docs/22)에 "좌석 데이터 확인일이 90일 지난 항공사" 항목을 추가한다.
  - 나라별 필수 항목 체크리스트(docs/19)와 같은 방식이다.

### 4.4 서버
- `services/flights.ts`의 `FlightInfo`에 `aircraft?: { code, registration? }`를 더한다.
  - 응답 줄 중 기종 값이 있는 가장 최근 줄을 쓴다.
- `guardApi`·`trackApi`는 그대로 쓴다. 호출 수는 늘지 않는다.

## 5. 단계 (CLAUDE.md: 새 기능은 실험실부터)

1. **1단계 — 기종 자동 채우기 + 기본 배열** (실험실 "기종·좌석 안내")
   - 서버: 기종·등록번호를 응답에 넣는다.
   - 웹: 예약 기종 칸 + 좌석 창가·통로·가운데 + 탑승권 기종 표시
   - [좌석 안내] 시트: 기본 배열 + 링크 3개
2. **2단계 — 국적사·LCC 좌석 메모 데이터** (약 30개 배열, 출처·확인일)
   - 시트에 비상구·넓은 줄·벽 앞·창문 없음을 표시하고 추천 줄을 요약한다.
3. **3단계 — 외항사 확대 + 월간 확인 항목** (사용자 결정 후)

예상 크기: 1단계 웹 +3KB(지연 로딩), 2단계 좌석 데이터는 항공사별 파일로 나눠 시트를 열 때만 받는다.

## 6. 테스트

- 도메인(Vitest)
  - 기종 코드 → 이름·배열
  - 좌석 → 창가·통로·가운데 (기종별 대표 3~4개)
  - 비상구·넓은 줄 판단
  - 등록번호로 배열 고르기
- 서버
  - 기종 값이 빈 코드셰어 줄은 건너뛴다.
  - 기종이 아예 없어도 시간·공항은 그대로 채운다.
- 화면
  - 불러오기 → 기종 칸이 채워진다.
  - 좌석 입력 → 특이사항 줄이 보인다.
  - 시트 칸을 누르면 설명이 나온다.
  - 데이터가 없으면 링크만 보인다.
- E2E: 360px에서 좌석 시트가 가로로 밀리고 화면 밖으로 넘치지 않는다.

## 7. 주의 (안내 문구에 넣을 것)

- 기종·좌석 배열은 **최근 운항 기준 참고 정보**예요.
  - 항공사 사정으로 기재가 바뀌면 좌석 번호와 위치도 달라질 수 있어요.
- 비상구석 배정 조건과 유료 여부는 항공사가 정해요. 체크인할 때 항공사 앱에서 확인하세요.
- 좌석 데이터는 항공사 공식 좌석 배치도를 보고 정리했고, 출처와 확인일을 함께 보여 줘요.

## 9. 확인 기록 (2026-10-28)

- AviationStack 무료 `flights?flight_iata=KE703` 실제 응답 (1회 사용):
  - 최근 운항 줄: `aircraft: { registration: "HL8572", iata: "B78X", icao: "B78X", icao24: "71C572" }`
  - 같은 날 다른 줄(코드셰어): `registration·iata·icao` 모두 null, `icao24`만 있음 → 값이 있는 줄을 골라야 한다
- AviationStack 요금: 무료는 실시간 운항만, 미래 일정·시간표는 유료 (공식 요금 페이지)
- Amadeus Self-Service 종료: 2026-07-17 (Phocuswire·AirLabs 정리 글 등). 기업 포털만 남음
- AirLabs 좌석 배치 페이지: "좌석 배치 API를 따로 제공하지 않음", Fleets API는 기종·등록번호만
- AeroDataBox: Basic(RapidAPI) 월 400 단위 무료, 엔드포인트별 1·2·6 단위
