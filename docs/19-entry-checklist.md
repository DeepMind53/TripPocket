# 19. 나라별 필수 항목 체크리스트 설계 (초안 — 사용자 확인 전 구현 금지)

> 2026-10-25 사용자 요청: 홈 "준비 현황"에 칸을 하나 더 — **필수 항목 체크리스트**. 한국인이 많이 가는 20개국만.
> 나라별 내용은 자주 바뀌므로 **확인한 날짜·공식 링크를 함께** 둔다. 결정은 §7.

## 1. 화면

### 1.1 홈 준비 현황 — 5번째 칸

```
┌ 준비 현황 ─────────────────────────────────┐
│ 🧳 준비물 3/12   │ 🎫 예약 항공1·숙소1      │
│ ☀️ 첫날 날씨     │ 💱 환율                  │
│ 🛂 필수 항목 체크리스트          2/7  ●    │  ← 새 칸 (가로 전체)
│   입국신고(Visit Japan Web) 아직이에요       │  ← 가장 급한 1개
└────────────────────────────────────────────┘
```

- 주황 점: 출발이 가까운데 못 한 "필수" 항목이 있을 때 (예: 태국 TDAC는 3일 전부터 — 출발 3일 전에 알림 점)

### 1.2 체크리스트 화면 (`/trips/:id/essentials`)

```
🇯🇵 일본 입국 필수 항목              확인: 2026-10-25 · 출처 보기
─ 꼭 ─────────────────────────────────────
☑ 여권 유효기간   귀국일까지 남아 있으면 됨 (일본)
                 [여권 만료일 입력 → 자동 확인] (이 기기에만 저장)
☐ 비자           한국인 무비자 90일 — 필요 없음 ✓ (자동 체크)
☐ 입국·세관 신고  Visit Japan Web (온라인) · 종이 신고서도 가능
                 출발 전 아무 때나 · [사이트 열기]
─ 이동 ───────────────────────────────────
☐ 공항 → 숙소 이동  예약에 픽업 있음 ✓ / 없으면: 나리타 익스프레스·리무진버스 [길찾기]
☐ 교통카드        Suica·PASMO (아이폰 지갑 앱에 넣기 가능)
─ 숙소 ───────────────────────────────────
☐ 체크인 시간 확인  15:00 (예약에서) · 늦게 도착하면 24시간 프런트 여부 확인
─ 권장 ───────────────────────────────────
☐ 여행자보험      권장 (의료비 비쌈)
☐ 전압·플러그     100V, A형 — 돼지코 필요
☐ 데이터(eSIM·로밍)
```

- 항목마다 **자동으로 판단할 수 있는 것은 자동 체크**:
  - 비자 필요 없음 → 자동 ✓ / 공항 이동 → 그 날짜에 픽업·드랍·렌터카 예약이 있으면 ✓ / 체크인 시간 → 숙소 예약에 시간이 있으면 ✓
  - 여권 유효기간 → 사용자가 만료일을 넣으면 "귀국일 기준 N개월 남음"으로 판단 (**여권 정보는 이 기기에만, 동기화·서버 저장 안 함**)
- 여러 나라 여행이면 나라별로 묶어 보여 줌, 같은 항목(여행자보험 등)은 한 번만
- 링크는 모두 **공식 사이트** (대행 유료 사이트 주의 문구)

## 4. 데이터

- `packages/shared/src/data/entryRules.ts` — 나라 코드별:
  ```ts
  { code: 'JP', checkedAt: '2026-10-25', sources: [url...],
    items: [
      { id: 'passport', level: 'must', rule: { minMonths: 0 } },          // 귀국일까지
      { id: 'visa', level: 'must', visaFree: { days: 90 } },
      { id: 'arrival', level: 'must', online: true, paper: true,
        name: 'Visit Japan Web', url: 'https://www.vjw.digital.go.jp/', from: 'any' },
      { id: 'transitCard', level: 'tip', text: 'Suica·PASMO·ICOCA' },
      { id: 'insurance', level: 'recommend' }, { id: 'power', level: 'tip', text: '100V A형' },
    ] }
  ```
- 공통 항목(공항 이동·체크인 시간·여행자보험·데이터)은 모든 나라에 붙임
- **체크 상태**: 여행별로 저장·동기화 — 준비 탭과 같은 `checklistItems`에 새 목록 종류 `essentials`를 더한다 (Dexie 버전 올림 + 마이그레이션 테스트, 백업 하위 호환)
- **여권 만료일**: 이 기기 설정에만 (동기화·서버·백업 제외) — 개인정보 최소화

## 5. 갱신

- 표의 `checkedAt`이 6개월 넘으면 화면에 "정보가 오래됐어요 — 출처에서 확인" 표시
- 관리자가 고칠 수 있게 할지는 다음 단계 (지금은 앱과 함께 배포)

## 6. 단계 (확인 후)

1. 20개국 데이터 + 공식 출처 확인 (나라마다 링크·확인일)
2. 체크리스트 화면 + 자동 체크(비자·예약·체크인 시간·여권)
3. 홈 준비 현황 5번째 칸 + 출발 전 알림 점
4. 문서·시험

## 7. 확인이 필요한 결정

1. **20개국 목록**: §2 제안 그대로? (괌·사이판을 미국과 따로, 유럽 3개국 + 영국)
2. **여권 만료일 입력**: 이 기기에만 저장하고 자동 판단(추천) / 입력 없이 안내 문구만
3. **권장 항목** (여행자보험·전압·데이터·환전) 도 넣을까요? (추천: "권장"으로 따로 묶어서)
4. 체크 상태를 **함께 여행하는 사람과 공유**(동기화, 추천) / 나만
