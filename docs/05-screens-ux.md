# 05. 화면 설계 / UX (상세 명세)

- 문서 상태: v0.2 (2026-10-22) — 디자인 시스템(`11-design-system.md`) 반영, 가계부 제외, 지도·장소·로그인 화면 추가
- 기준 뷰포트: **360×780** 모바일 우선 → 600px+ 지도/목록 좌우 분할
- 시각 시안: `docs/design/mockups.html`

## 1. 내비게이션 맵
```
앱 하단 탭 ─┬─ 🏠 홈 (S-01)
            ├─ 🧳 내 여행 (S-02) ──▶ 여행 만들기 (S-03a~c)
            ├─ ❤️ 저장 (S-04)
            └─ 👤 마이 (S-05) ──▶ 로그인 (S-20) · 계정/기기 (S-21) · 백업/복원 (S-22) · 설정 (S-23)

여행 상세 (앱 탭 숨김, 여행 탭 표시)
            ├─ 📅 일정 (S-10) ──▶ 일정 추가 시트 (S-11) · 일정 상세 (S-12) · 편집 모드 (S-13)
            ├─ 🔍 장소 (S-14) ──▶ 장소 상세 (S-15)
            ├─ 🎫 예약 (S-16) ──▶ 예약 편집 (S-17)
            ├─ ✅ 준비 (S-18)
            └─ 헤더 ⋯ ──▶ 여행 설정 (S-19) · 멤버/초대 (S-24) · 공유/내보내기 (S-25)

공통 시트: 길찾기 (S-30) · 다른 날로 이동 (S-31) · 날짜 범위 선택 (S-32)
빠른 메뉴(⚡, 모든 화면 헤더): 빠른 메뉴 시트 (S-50) ──▶ 환율 계산기 (S-51) · AI 추천 (S-52) · 설정 (S-23)
외부 진입: 공유 일정 보기 /s/:id (S-40) · 초대 수락 /invite/:token (S-41) · 설치 안내 (S-42)
```

## 2. 화면 명세 템플릿
각 화면은 다음 항목으로 정의한다: **목적 · 진입 · 구성 · 주요 동작 · 상태(로딩/빈/오류/오프라인) · 예외 · 우선순위**

## 3. 앱 레벨 화면

### S-01 홈
- **목적**: 앱을 열면 "지금 필요한 것"을 바로 보여준다 (여행 중 3초 규칙).
- **구성 (상황별)**
  | 상황 | 표시 |
  |---|---|
  | 여행 중 | 상단 "여행 중 · 2일차" 카드 → **다음 일정** 크게(시간, 이름, 남은 시간, [길찾기]) → 오늘 일정 목록 → 오늘 숙소 띠(예약번호 복사) |
  | 다가오는 여행 있음 | D-day 카드(커버 색·이모지, 기간) → "준비물 7/20" 진행 바 → [일정 보기] |
  | 여행 없음 | 빈 상태: "어디로 떠나볼까요?" + [새 여행 만들기] |
  | 공통 하단 | 알림 띠(조건부): 백업 권유 / 동기화 오류 / 설치 권유 — 한 번에 1개만 |
- **동작**: 다음 일정 카드 탭 → S-12, [길찾기] → S-30
- **예외**: 여행 2개가 겹치면 시작일이 빠른 여행 우선 + "다른 여행 보기" 링크
- **우선**: P0

### S-02 내 여행
- **구성**: 상단 제목 "내 여행" + 우측 [+] / 섹션: 여행 중 · 다가오는 여행 · 다녀온 여행(접힘)
- **여행 카드**: 커버(색+이모지) · 제목 · `2026.10.24 – 10.28 · 4박 5일` · D-day 배지 · 멤버 아바타(공동 편집 시) · 동기화 아이콘
- **동작**: 카드 탭 → S-10 / 길게 누르기 → 메뉴(복제, 보관, 삭제)
- **빈 상태**: 🧳 "아직 여행이 없어요" [첫 여행 만들기]
- **우선**: P0

### S-03 여행 만들기 (단계형, 토스식 한 화면 한 질문)
| 단계 | 질문 (display 28px) | 입력 | 하단 CTA |
|---|---|---|---|
| a | "어디로 떠나세요?" | 도시 검색 + 추천 칩(도쿄, 오사카, 후쿠오카, 제주, 부산, 방콕, 다낭, 파리…) — 여러 개 선택 가능 | [다음] |
| b | "언제 떠나세요?" | 날짜 범위 달력 (S-32), "날짜 미정"도 허용 ⚠️ | [다음] |
| c | "여행 이름을 정해주세요" | 자동 제안 "도쿄 여행" + 이모지/색 선택 | [여행 만들기] |
- 완료 후 → S-10 일정 화면 + 코치마크 "가고 싶은 곳부터 담아보세요"
- 도시 선택 시 타임존·지도 제공자 자동 결정 (도쿄 → Asia/Tokyo, 구글 / 제주 → 네이버)
- 상단 진행 표시 (1/3), 뒤로 가기 시 입력 유지
- **우선**: P0

### S-04 저장 (찜한 장소)
- **목적**: 여행과 무관하게 "언젠가 가고 싶은 곳"을 모은다 (트리플·구글맵 저장 패턴).
- **구성**: 도시 필터 칩(도쿄 · 제주 · 전체) / 종류 필터 / 장소 카드 목록 / [지도로 보기]
- **동작**: 카드 → [여행에 담기] → 여행 선택 → 날짜 선택(또는 '가고 싶은 곳')
- **빈 상태**: ❤️ "마음에 드는 장소를 저장해 보세요" [장소 찾기]
- **우선**: P1

### S-05 마이
- **구성**
  - 비로그인: "로그인하면 여러 기기에서 여행을 이어서 볼 수 있어요" [로그인] (강요하지 않음)
  - 로그인: 닉네임 · 로그인 방식(네이버 등) · 동기화 상태 "방금 동기화됨"
  - 메뉴: 백업·복원 / 지도 앱 설정(기본 길찾기 앱) / 화면(다크 모드, 시간 표기) / 저장공간 / 도움말 / 개인정보처리방침 / 이용약관 / 오픈소스 라이선스 / 버전 정보 / 로그아웃 / 회원 탈퇴
- **우선**: P0

## 4. 여행 상세 화면

### 공통 헤더
`← | 🗼 도쿄 가을여행 ▾ | ☁️(동기화) ⚡(빠른 메뉴) ⋯(공유·설정)`
- 제목 아래 보조줄: `10.24 (금) – 10.28 (화) · D-2`
- 제목 탭 → 여행 설정(S-19)

### S-10 일정 (핵심 화면)
- **레이아웃**: 상단 **지도(높이 40%)** + 아래 **목록 시트**(끌어올리면 지도 접힘, 내리면 지도 확대) — 트리플/Wanderlog 공통 패턴
- **Day 칩**: `전체 | 1일차 10.24 | 2일차 10.25 | … | 가고 싶은 곳` (가로 스크롤, 오늘 칩에 점 표시, 색 점 = Day 색)
- **목록 (Day 섹션)**
  ```
  2일차 · 10.25 (토)                     [⋯]
  ① 09:00  🏯 센소지              관광
           아사쿠사 2-3-1
     ┆ 직선 2.1km · 길찾기
  ② 11:30  🍜 이치란 라멘          맛집
     ┆ 직선 650m · 길찾기
  ③ —      🛍 긴자 쇼핑            쇼핑
  [+ 일정 추가]
  ━━ 🛏 숙소 · 신주쿠 그레이스리 호텔 (2/4박) ━━
  ```
  - 번호 원 = Day 색 + 순서 (지도 핀과 동일)
  - 카드 사이 `TravelGap`: 직선거리(좌표 있을 때만) + 길찾기 링크. **소요시간은 표시하지 않음**(API 비용) — 길찾기 앱에서 확인
  - 시간 없는 일정은 `—` 표시
  - 다녀온 일정은 체크 표시 + 흐리게 (여행 중일 때만 체크 버튼 노출)
- **지도**: 선택 Day의 핀 + 순서선, `전체` 선택 시 모든 Day 색상별 표시, 핀 탭 → 목록 해당 카드로 스크롤 + 강조
- **동작**
  - 카드 탭 → S-12 상세 시트
  - [+ 일정 추가] → S-11
  - Day [⋯] → 시간순 정렬 / 이 날 일정 비우기 / 다른 날과 바꾸기
  - 헤더 우측 또는 목록 상단 [편집] → S-13
- **상태**
  - 빈 Day: "아직 일정이 없어요" + [장소 찾기] [직접 추가]
  - 오프라인: 지도 영역에 "지도는 인터넷 연결 시 보여요" + 목록은 정상
  - 지도 로딩 실패: 지도 영역 접고 목록만
- **우선**: P0 (지도 부분은 M4.5)

### S-11 일정 추가 시트
- 탭 3개: **검색** (장소 검색, 로그인 시) / **저장한 장소** / **직접 입력**
- 직접 입력 폼: 종류 칩(관광·맛집·카페·쇼핑·이동·숙소·액티비티·메모) → 이름* → 시간(시작/종료, 선택) → 주소(선택) → 메모 → 링크
- 날짜 선택: 기본 = 현재 보고 있는 Day, "가고 싶은 곳에 담기" 옵션
- CTA: [일정에 추가] (하단 고정), 추가 후 시트 유지 옵션 "계속 추가"
- **우선**: P0

### S-12 일정 상세 시트
- 상단: 종류 아이콘 · 이름 · 시간 · Day
- 액션 줄 (아이콘 버튼 4개): **[길찾기]** [주소 복사] [지도에서 보기] [편집]
- 정보: 주소, 메모, 링크, 연결된 예약(예약번호 복사), 첨부(P1)
- Google 장소면: 평점·리뷰 수 요약 + [리뷰 보기] → S-15 (온라인일 때만 실시간 조회)
- 하단: [다른 날로 이동] [삭제]
- 편집은 같은 시트에서 인라인 → 자동 저장
- **우선**: P0

### S-13 편집 모드 (순서 바꾸기)
- 트리플식 명시적 편집 모드: [편집] 탭 → 카드 왼쪽에 핸들(⠿), 오른쪽에 체크박스
- 드래그로 순서 변경, Day 경계 넘어 이동 가능
- 다중 선택 → 하단 바: [다른 날로 이동] [삭제]
- [완료]로 종료. 실수 시 스낵바 "실행 취소"
- 접근성 대체: 각 카드 메뉴에 "위로 / 아래로 / 다른 날로"
- **우선**: P0

### S-14 장소 찾기
- 상단: 검색창 ("도쿄에서 무엇을 찾으세요?") + 기준 위치 선택 `[여행지 중심 ▾ | 숙소 근처 | 내 위치]`
- 카테고리 칩: 🏨숙소 · 🍜맛집 · ☕카페 · 🏯관광 · 🛍쇼핑
- 필터 줄: `⭐ 4.0+ ▾` `리뷰 100+ ▾` `가격 ▾` `영업 중` `거리 ▾` → 필터 시트(S-14f)
- 정렬: 추천순(가중 평점) / 평점순 / 리뷰 많은순 / 가까운순
- 결과: [목록 | 지도] 토글. 카드 = 이름 · ⭐4.4 (3,210) · ₩₩ · 영업 중 · 종류 · 거리 · [❤️] [+ 담기]
- 하단 출처 "Powered by Google" / 네이버 결과는 "네이버 지도에서 리뷰 보기"
- **상태**
  - 비로그인: 검색창 대신 안내 "장소 검색은 로그인 후 쓸 수 있어요" [로그인] + [직접 추가]
  - 오프라인: "인터넷 연결 후 검색할 수 있어요"
  - 일일 한도 초과: "오늘 검색 횟수를 모두 썼어요. 내일 다시 이용해 주세요"
  - 결과 없음: "조건에 맞는 곳이 없어요" + [필터 초기화]
- **우선**: P0 (M4.5)

### S-15 장소 상세
- 사진(선택, 과금 검토 ⚠️) · 이름 · 종류 · ⭐ 평점 + 리뷰 수 · 가격대 · 영업 상태/오늘 영업시간
- 액션: [+ 일정에 담기] [❤️ 저장] [길찾기] [전화] [웹사이트]
- 리뷰 (최대 5개): 작성자 · 별점 · 상대 날짜 · 본문(3줄 접기) · 원문 번역 여부 표기
- [Google 지도에서 리뷰 더 보기] (외부)
- **우선**: P0

### S-16 예약
- 그룹: ✈ 항공 / 🛏 숙소 / 🚆 교통 / 🎟 투어·티켓 / 기타 (날짜순)
- 항공 = 탑승권 카드, 숙소 = 체크인·체크아웃 카드(박 수), 기타 = 기본 카드
- 예약번호 탭 → 복사 토스트 "예약번호를 복사했어요"
- 빈 상태: 🎫 "항공권, 숙소 예약을 모아두면 여행 중에 바로 꺼내볼 수 있어요" [예약 추가]
- **우선**: P0

### S-17 예약 편집 시트
- 1단계: 종류 선택 (항공 / 숙소 / 기차·버스 / 렌터카 / 투어·티켓 / 기타)
- 2단계: 종류별 폼
  - 항공: 편명, 항공사, 출발(공항·날짜·시간), 도착(공항·날짜·시간), 좌석, 예약번호 — 타임존은 공항으로 자동 ⚠️(공항 DB 필요 여부 결정)
  - 숙소: 숙소명(장소 검색 연동), 주소, 체크인/아웃 날짜·시간, 예약번호, 연락처, 결제 메모
- 저장 시 숙소는 해당 날짜 S-10 하단 띠에 자동 표시
- **우선**: P0

### S-18 준비
- 탭: **준비물** / **할 일**
- 상단 진행 바 "12/30 챙겼어요"
- 카테고리 아코디언(서류 · 전자기기 · 의류 · 세면도구 · 상비약 · 기타), 항목 체크, 스와이프 삭제
- [템플릿 불러오기] → 해외 기본 / 휴양지 / 겨울 / 아이 동반 / 내 템플릿
- 할 일 기본 제안: 여권 유효기간 확인, 유심/eSIM, 여행자 보험, 환전, 공항 이동 확인
- **우선**: P0

### S-19 여행 설정
- 여행 이름·이모지·색, 목적지, 기간 변경(→ 영향 미리보기: "3일차 일정 4개가 '가고 싶은 곳'으로 이동해요"), 타임존, 지도 제공자(자동/구글/네이버), 복제, 보관, 삭제
- **우선**: P0

## 5. 계정 · 데이터 화면

### S-20 로그인
- 제목 "로그인하고 어디서든 이어보세요"
- 버튼: [N 네이버로 계속하기] [카카오로 계속하기] [G Google로 계속하기] (각 브랜드 가이드 준수 ⚠️)
- 하단: "로그인하면 이용약관과 개인정보처리방침에 동의하게 돼요" (링크), [로그인 없이 사용하기]
- 첫 로그인 후: "이 기기에 여행 3개가 있어요. 내 계정에 저장할까요?" [저장하기] [나중에]

## 7. 인터랙션 규칙
| 상황 | 규칙 |
|---|---|
| 삭제 | 즉시 삭제 + 스낵바 "삭제했어요 [실행 취소]" 4초. 여행 전체 삭제만 확인 다이얼로그 |
| 저장 | 생성은 하단 CTA, 편집은 자동 저장 (저장됨 표시 없음, 실패 시만 알림) ⚠️ C2 |
| 뒤로 가기 | 시트 열림 → 시트 닫기 우선 (Android 뒤로 버튼·iOS 스와이프 대응, URL 상태 연동) |
| 복사 | 예약번호·주소 탭 → 클립보드 + 토스트 "복사했어요" |
| 로딩 | 300ms 이내는 표시 없음, 이후 스켈레톤. 버튼 액션은 버튼 내부 스피너 |
| 오류 | 인라인(폼) / 스낵바(액션) / 전체 화면(복구 불가) 3단계. 문구는 원인 + 해결 |
| 오프라인 | 온라인 필요 기능만 비활성 + 이유. 앱 전체 배너 없음. 헤더 구름 아이콘에 대기 상태 |
| 동기화 충돌 | 자동 처리(최신 우선) + "다른 기기에서 수정된 내용으로 바뀌었어요 [이전 내용 보기]" 스낵바 |
| 첫 사용 | 코치마크 최대 2개 (일정 추가, 편집 모드). 다시 보지 않기 |
| 햅틱 | 드래그 시작·완료, 체크 (지원 기기만) |

## 8. 주요 사용자 흐름 (E2E 시나리오 기준)
1. **첫 여행 만들기**: 앱 열기 → [새 여행 만들기] → 도쿄 → 10.24–10.28 → [여행 만들기] → 일정 화면 (목표 30초)
2. **장소 찾아 담기**: 장소 탭 → 맛집 → ⭐4.0+ · 리뷰 100+ → 카드 [+ 담기] → 2일차 → 일정 탭에서 확인
3. **여행 중 길찾기**: 홈 → 다음 일정 [길찾기] → 대중교통 → 네이버 지도 앱 열림
4. **순서 바꾸기**: 일정 → [편집] → 드래그 → [완료] → 새로고침 후 유지
5. **로그인·동기화**: 마이 → 로그인(네이버) → 로컬 여행 업로드 → 다른 기기 로그인 → 동일
6. **가족에게 공유**: ⋯ → 공유 → 보기 전용 링크 → 카톡 → 가족이 로그인 없이 열람·길찾기
7. **환율 계산**: ⚡ → 환율 카드 → ¥3,500 입력 → 원화 즉시 표시 → 오프라인에서도 마지막 환율로 동작
8. **오프라인**: 비행기 모드 → 앱 열기 → 일정·예약번호 조회·편집 → 온라인 복귀 → 자동 동기화
